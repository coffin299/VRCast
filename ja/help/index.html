かんたんスタート

VRCast は VRChat 用のアバターを単体で表示し、OBS などの配信ソフトに映すアプリです。 VRCast を起動すると左のパネルに はじめに タブが開き、同じ手順を画面上で案内します。

  1. Unity でアバターを .vrcaster ファイルに書き出す
  2. .vrcaster を VRCast のウィンドウにドラッグ＆ドロップ
  3. VRM（.vrm、VRoid など）なら書き出し不要で、そのままドラッグ＆ドロップ（VRM について）
  4. はじめに タブの 透過にする を押す
  5. OBS で ゲームキャプチャ を追加して 透過を許可
  6. Tab キーで操作パネルを隠す

1. アバターを書き出す（Unity）

アバターの入った Unity プロジェクト（VCC で作ったプロジェクトで OK、Unity 2022.3.22f1）で作業します。

  1. 配布 zip の VRCast-Converter フォルダ（本体の VRCast フォルダとは別）にある VRCast-Converter-バージョン.unitypackage をダブルクリック（または Unity にドラッグ＆ドロップ）して Import を押します（Assets/VRCast/Converter に入ります）。
  2. メニュー VRCast > Avatar Exporter を開きます。
  3. シーン上のアバター（一番上の親オブジェクト）を指定して 書き出す... を押し、保存先を選びます。 画面は Unity の OS の言語で表示されます（上部の 言語 で切り替え可能）。

元のアバターは変更されません。表情・口パク・まばたき・揺れもの・Constraint の設定も一緒に書き出されます。

シーン上で非アクティブ（チェックを外した）オブジェクトは、子も含めて書き出されません。表示したい衣装・小物はアクティブにしてから書き出してください。

ブレンドシェイプは Unity のシーンで設定した値のまま書き出されます（シーンのブレンドシェイプの値を優先する、既定 ON）。 衣装の切り替えに合わせて縮小用ブレンドシェイプを FX で動かしている場合などは、OFF にすると VRChat に入ったときの初期状態の値で書き出します。

FX レイヤーにある表情クリップは自動で書き出されます。FX に入っていない表情（昔のアバターに付属していた表情アニメーションなど）は、 書き出し画面の 追加の表情 にアニメーションクリップかフォルダをドラッグすると表情として書き出せます（ブレンドシェイプだけを動かすクリップが対象。指定はアバターごとに保存）。

【ベータ版】Modular Avatar などで改変したアバターは、そのまま指定すれば改変後の姿（衣装の統合・追加した表情やトグル）で書き出されます。 MA の Merge Armature / Bone Proxy で付けた衣装・小物は、統合されなかった場合でもアバターのボーンに付け替えて体に追従させます。 MA の Blendshape Sync で口などに追従させたチェーン・小物も、口パク・まばたき・トラッキングに追従します。 暫定対応のため、正しく書き出せない場合があります。

Package Manager で入れる場合は、Window > Package Manager の + > Add package from git URL... に https://github.com/coffin299/VRCast.git?path=/Packages/com.vrcast.converter を入力します（Git が必要）。unitypackage と両方入れるとエラーになるので、どちらか一方にしてください。

2. VRCast で読み込む

  • .vrcaster または .vrm ファイルを VRCast のウィンドウにドラッグ＆ドロップすると読み込まれます。
  • または はじめに タブの ファイルを選ぶ...、 アバター タブの 参照... で選べます。
  • 最後に読み込んだアバターは次回起動時に自動で読み込まれます。
  • アバター タブの 最近使ったアバター に直前に使ったアバターが最大 10 件並び、クリックで切り替えられます（× で一覧から外します）。 カメラ・ライト・アバターの明るさ・待機ポーズ・体の向きはアバターごとに記憶され、切り替えると戻ります。

.vrcaster と .vrm 以外のファイル（画像や unitypackage など）は読み込めません。.vrcaster でエラーが表示された場合は書き出し直してください。

VRM を読み込む

  • VRM 0.x / 1.0 の .vrm（VRoid Studio などで作ったもの）は、Unity での書き出しをせずにそのまま読み込めます。
  • VRM の表情（喜怒哀楽・驚き・独自の表情）、まばたき・ウインク、あいうえおの口の形、揺れもの（SpringBone）を VRCast の表情・自動まばたき・口パク・揺れものとして使います。
  • アバター タブに VRM のバージョン（0.x / 1.0）と作者が表示されます。

マテリアルの色を変える表情、VRM のコンストレイント、目のボーンが無いモデルの視線（BlendShape 方式）は反映されません。VRM に書かれた利用条件を守って使ってください。

3. OBS に映す

  1. VRCast の はじめに タブ（または 表示 タブ）で背景を 透過 にします。 VRCast の画面では背景色のまま見えますが、OBS では背景が抜けます。
  2. OBS の ソース の + から ゲームキャプチャ を追加します。
  3. モードを 特定のウィンドウをキャプチャ、ウィンドウを [VRCast.exe]: VRCast にします。
  4. 透過を許可 にチェックを入れます。
  5. VRCast で Tab キーを押して操作パネルを隠します（パネルも OBS に映るため）。隠している間は、透過を OFF にしていても OBS では背景が抜けます。

ウィンドウキャプチャ は透過に対応していません。透過したいときは必ず ゲームキャプチャ を使ってください。

仮想カメラ（Discord / Zoom など）

  1. 出力 タブで仮想カメラの出力を ON にします。
  2. 初回だけ ドライバーを登録 を押します（管理者の確認が出ます）。
  3. 使いたいアプリのカメラ選択で VRCast Camera を選びます（出ない場合はそのアプリを再起動）。

操作パネルは仮想カメラには映りません。Discord などは透過できないため、背景は背景色で映ります。 VRCast のフォルダを移動・削除する前に ドライバーを解除 を押してください。

出力タブに「準備できました」と出ている間は、まだどのアプリもカメラを開いていない状態です（エラーではありません）。受け取る側のアプリで VRCast Camera を選ぶと「送信中」に変わります。

Discord などでカメラが起動しないとき（Windows 11）

  1. 出力 タブで Windows 11 の方式（Media Foundation）で出力する を ON にします。
  2. この方式のドライバーを ドライバーを登録 で登録します（方式ごとに 1 回。管理者の確認が出ます）。
  3. 使いたいアプリで VRCast Camera (MF) を選びます。

Windows の通常のカメラとして扱われるため、従来の方式が一覧に出ない・起動に失敗するアプリでも使えることがあります。VRCast の起動中で出力が ON の間だけ一覧に出ます。ドライバーは Program Files にコピーされるため、VRCast のフォルダを移動しても登録し直す必要はありません。

Spout2（OBS へ軽く・透過のまま）

  1. OBS に Spout2 プラグイン を入れます。
  2. 出力 タブの Spout2 で 出力する (VRCast) を ON にします。
  3. OBS で Spout2 Capture ソースを追加し、送信元に VRCast を選びます。

GPU 上で映像を渡すので、ゲームキャプチャや仮想カメラより軽く、背景の透過もそのまま届きます。操作パネルは映りません。解像度は VRCast のウィンドウの大きさです。

見た目・ライト（表示タブ）

項目 内容
カメラ 画角の変更とリセット。右ドラッグで回転、中ドラッグで移動、ホイールでズーム。カメラの位置と画角はアバターごとに記憶され、再起動後も戻ります。カメラを固定 を ON にすると、マウスのドラッグ・ホイールで動かなくなります（画角とリセットは使えます）。
背景 背景色（既定はベージュ）と透過の切り替え。透過中も VRCast の画面では背景色が見えますが、OBS のゲームキャプチャでは抜けます。
解像度 ウィンドウの大きさ（横長・縦長のプリセット）。
ライト 環境光 はアバター全体を均一に明るく、太陽光 は一方向から照らします。 暗いときは 晴れ プリセットを押すか環境光を上げてください。太陽光の色 は低いほど暖色。 向き 0 で正面から当たります。ライトで明るくならないときは アバターの明るさ を上げます。ライトとアバターの明るさはアバターごとに記憶されます。

ポーズ・表情 タブではアバターの向き・腕の下ろし方・表情を変更できます。 表情ごとにショートカットキーを割り当てられます（既定はすべて未割り当て）。キーのボタンを押してから割り当てたいキーを押し（Ctrl+Alt+N のような同時押し、テンキー（NumLock ON で数字キーと区別）、記号キー、右 Ctrl などの単独（押して離す）、マウスのサイドボタンも可）、Esc でやめられます（Tab は使えません）。隣の リセット で割り当てを外します（アバターごとに保存）。 VRCast が背面にあるときも使う（既定 ON）なら、OBS などを操作中でも切り替えられます。ほかのアプリで文字を入力している間も反応するため、Ctrl や Alt との組み合わせがおすすめです。 ボタン・キーで選んだ表情は固定され、トラッキングの自動検出では変わりません。同じ表情をもう一度選ぶか 自動検出に戻す で元に戻ります。 OSC / HTTP タブ（出力と設定の間）で 外部から操作（OSC / HTTP） を ON にすると、表示中のアバターの表情ごとのコマンドが一覧に並び（コピー でコピー）、ポートの下に OSC の送信先と HTTP の URL が表示されます（ブラウザで状態を開く で動作確認。Stream Deck では「Web サイト」の「バックグラウンドで GET」に URL 全体を設定）。Stream Deck や OSC アプリから表情を切り替えられます（この PC からのみ。例: http://127.0.0.1:39571/expression?name=Smile&toggle=1、OSC /vrcast/expression "Smile"。番号は 0 = ニュートラル、1 以降 = 表情の並び順）。

待機モーション（既定 ON、Humanoid のみ）は、Web カメラを使っていないときにアバターが完全に止まって見えないよう、呼吸・体の揺れ・頭のゆらぎを少し足します。 呼吸・体の揺れ を OFF にすると止まります。ON のときは 呼吸・体の揺れ・頭のゆらぎ の強さ（0〜2、1 が標準）と 速さ（0.5〜2 倍）を調整できます。 顔のトラッキング中は頭のゆらぎを止め、本人の動きに任せます。

口パク・まばたき（顔タブ）

  • マイクで口パク を ON にしてマイクを選び、音量 メーターを見ながら マイク感度 と ノイズゲート（この音量以下は無音）を調整します。
  • 母音で口の形を変える が ON なら、VRChat と同じように「あいうえお」で口の形が変わります。 判定がずれるときは 声の高さ補正 を動かします（声が高い人は右）。
  • 揺れもの（PhysBone の近似）と自動まばたきも ON/OFF できます。
  • 表情中はまばたきしない を ON にすると、表情を出している間は自動まばたきもトラッキングのまばたきも止まり、表情の目の形が崩れません。
  • 表情中はマイクの口パクを止める・表情中はトラッキングの口を止める を ON にすると、表情を出している間はそれぞれの口の動きが止まります（別々に選べ、両方 ON にもできます。表情の口とリップシンクが重なると崩れるアバター向け）。
  • シェイプキー設定 タブの BlendShape の上限 では、BlendShape ごとに動く最大値（100 = 制限なし）を決められます。まばたきで目が消える・口を開くと顔が崩れるときは、その BlendShape を下げてください。 対象 で 顔（まばたき・口・表情）（まばたき・口パク・表情・パーフェクトシンクで動くもの）か その他（体型・服など）を選び、検索 で絞り込めます。設定はアバターごとに保存されます。

Web カメラトラッキング（トラッキングタブ）

  • トラッキングを有効にする を ON にすると、同梱のトラッカーが自動で起動し、頭の向き・まばたき・口・視線（MediaPipe では腕・手も）が動きます。
  • MediaPipe で 腕・手 が ON のときは、上半身のひねり・傾き（肩）（既定は ON）で両肩の向きに合わせて上半身をひねったり左右に傾けたりします。肩が映っていない間は頭の位置で傾けます。ひねらせたくないときは 上半身のひねりを固定 を ON にすると、左右の傾きだけが動きます。生データ表示 では上半身の向きが緑の箱と角度で確認できます（骨格はアバターの大きさに合わせて描くので、カメラを動かす必要はありません）。
  • 入力元 は、縦に並んだスイッチのどれか 1 つを ON にして選びます。各行の右（幅が足りないときはスイッチの下）に推奨（MediaPipe）と PC 負荷の目安（低・中・高）が出ます。MediaPipe は 腕・手 を OFF にすると軽くなり、iPhone などから受け取る入力元は推定をスマートフォン側で行うため PC の負荷は低めです。
  • まばたきをトラッキング（既定は ON）を OFF にすると、目の開閉は追わず、顔タブの自動まばたきでまばたきします（パーフェクトシンクでもまばたきだけは動かしません）。
  • 閉じた目・ウインクが頭の傾きや腕と逆側になるときは、動き 欄の 顔の左右を入れ替える（既定は OFF）を ON にします。顔（まばたき・パーフェクトシンク・視線）だけが入れ替わり、頭の向きと腕は ミラー の設定のままです。
  • MediaPipe・iPhone・外部アプリ（VMC）・iFacialMocap では 表情を反映 を ON にすると（既定は ON）、笑顔・驚き・怒り・悲しみ・ウインク・ジト目・ふくれっ面を検出してアバターの表情に切り替えます（割り当て先の表情が無いものは検出しません）。 表情ごとの しきい値 で反応のしやすさ（低いほど反応しやすい。生データ表示 中に出る表情の値が目安）を、表情ごとの選択で使う表情を変えられます（自動 は表情の名前から推定）。
  • MediaPipe・iPhone・外部アプリ（VMC）・iFacialMocap では パーフェクトシンク（既定は ON）にも対応しています。ARKit 名の BlendShape（eyeBlinkLeft・jawOpen・mouthSmileLeft など）を持つアバターなら、眉・頬・口の形まで顔の動きどおりに動きます。 有効にする条件 で 20 種類以上（既定）か 1 種類でも を選べ、対応しているかはその下に件数で表示されます。パーフェクトシンク中は 表情を反映 の自動切り替えは止まります（20 種類未満で動かしているときは併用します）。
  • カメラは < > で選びます。動かないときは トラッカーを再起動。
  • 入力元を iPhone・外部アプリ（VMC、顔のみ） にすると、カメラの代わりにスマートフォンのアプリ（iPhone の Waidayo など）から VMC プロトコルで顔の動きを受け取ります。 PC とスマートフォンを同じ Wi-Fi につなぎ、トラッキングタブに出る この PC の IP アドレス と UDP ポート（既定 39539）をアプリの送信先に入力してください。 初回は Windows ファイアウォールの確認が出るので、プライベートネットワークで許可してください。ARKit の値を送るアプリなら、パーフェクトシンクと表情の反映も使えます（腕・手は動きません）。
  • 入力元を iFacialMocap（iPhone、顔のみ） にすると、iPhone の iFacialMocap から顔の動きを受け取ります。 PC と iPhone を同じ Wi-Fi につなぎ、iFacialMocap の画面上部に出る IP アドレスをトラッキングタブの iPhone の IP アドレス に入力してください（UDP ポート 49983 を使います）。 初回は Windows ファイアウォールの確認が出るので、プライベートネットワークで許可してください。パーフェクトシンクと表情の反映も使えます（腕・手は動きません）。
  • 正面がずれたらカメラを見て、パネル下部の リセット の 顔の向き（顔・上半身・視線）を押します。視線だけなら 視線。
  • 正面は、トラッキング開始時（入力元・カメラの変更後も）に頭が 0.5 秒ほど止まったときの向きで自動で決まります。顔を手で隠すなどして見失っても、正面は取り直しません。
  • 体の動き で、頭の動きに合わせて上半身を傾けるか体ごと動かすかを選べます。

他のアプリ（Discord・Zoom・VSeeFace など）が Web カメラを使っていると起動できません。

設定・リセット（設定タブ）

  • 表示言語: 自動（OS に合わせる）/ English / 日本語 / 한국어 / 简体中文 / 繁體中文。パネル上部の言語ボタンでも、どのタブからでも切り替えられます。
  • UI の大きさ: 75%〜200%。
  • テーマ: ライト（既定）/ ダーク。背景色を表示タブで変えていなければ、背景もテーマに合わせて切り替わります。
  • 軽量モード（既定は ON）: 描画を 30fps（OFF なら 60fps）に抑え、OpenSeeFace は軽いモデルを使って、ゲームや OBS と同時に使うときの負荷を減らします。MediaPipe の重さはトラッキングタブの トラッカーの動作 で選びます。
  • 動作状況を表示（既定は ON）: パネルの一番下に、描画の FPS・VRCast の CPU 使用率・GPU の処理時間・同梱トラッカーの CPU 使用率・トラッキングの受信レートを英語で表示します（1 秒ごとに更新）。重いときの原因の見当をつけるのに使えます。
  • プロセスの優先度（既定は「通常」）: VRCast 本体と同梱トラッカーの優先度をまとめて変えます（すぐ反映）。ゲーム中にトラッキングがカクつくときは上げてください。「高」にすると他のアプリが重くなることがあります。
  • CPU 設定 › AMD（X3D）› 3D V-Cache の無い側のコアで動かす（既定は ON。効果があるのは 7950X3D / 9950X3D など、3D V-Cache が片方の CCD にだけある CPU だけです。この PC が対象かどうかは設定の下に表示されます）: ゲーム中は Windows がアプリをゲームと同じコアに寄せるため、VRCast 本体と同梱トラッカーを反対側のコアで動かし、ゲームとコアを取り合わないようにします（すぐ反映）。VRCast 自体がゲームと判定されている場合は、Game Bar（Win + G）の設定で「これをゲームとして記憶する」をオフにしてください。
  • CPU 設定 › Intel（P コア / E コア）› 使うコア（既定は「自動」。効果があるのは P コアと E コアがある Intel の CPU（第 12 世代以降・Core Ultra）だけです）: VRCast 本体と同梱トラッカーを動かすコアを選びます（すぐ反映）。E コアのみ は P コアをゲームに譲りますが、トラッキングや描画が遅くなることがあります。P コアのみ は速く動きますがゲームとコアを取り合います。迷ったら「自動」のままで大丈夫です。
  • 描画に使う GPU（既定は「自動」）: 自動 / 省電力 / 高パフォーマンス、または GPU を一覧から直接選べます。VRCast を起動し直すと反映されます（VRCast を今すぐ起動し直す ボタン。PC の再起動は不要です）。OBS のキャプチャや仮想カメラを使うときは、OBS と同じ GPU にすると最も軽くなります。同梱トラッカーは CPU で動くので、この設定は関係しません。
  • NVIDIA インスタントリプレイ（NVIDIA の GPU がある PC だけ表示）: NVIDIA のインスタントリプレイに検知させない を押すと、VRCast がインスタントリプレイ（ShadowPlay）にゲームとして検知されないよう、ドライバー設定に VRCast 用のプロファイルを書きます。VRCast を起動し直すと反映されます。NVIDIA のインスタントリプレイの検知を元に戻す で元に戻せます。非公式の設定のため、ドライバーによっては効きません。変更できないと表示されたときは、VRCast を管理者として実行してお試しください。
  • アップデート: 起動時に新しいバージョンがあるかを確認し、あればパネル上部に通知します（GitHub からダウンロード / BOOTH からダウンロード / 更新履歴を表示する（GitHub））。 確認は最新のバージョン番号を読むためだけに Web サイト（coffin299.github.io）へ接続します。OFF にもできます。
  • 設定は VRCast の終了時に自動で保存され、次回起動時に復元されます。
  • 開発者・協力者とライセンスは クレジット タブで確認できます。 開発者の Twitch チャンネル もここから開けます。フォローや Prime サブスクをしてくれると開発の励みになります。

全ての設定をリセット（赤いボタン）を押し、確認で リセットする を押すと、全ての設定が初期状態に戻ります （ウィンドウサイズと最後に開いたアバターは残ります）。元に戻せません。

困ったとき

アバターが暗い

表示 タブの 晴れ プリセットを押すか、環境光 を上げてください。 向き を 0 付近にすると正面から光が当たります。 lilToon 等は明るさがテクスチャの色までに制限されるため、太陽光を上げても一定以上は明るくなりません。 その場合は アバターの明るさ を上げてください（0.5〜10、1 = マテリアルのまま）。

OBS で背景が抜けない

VRCast の背景を 透過 にし、OBS は ゲームキャプチャ（ウィンドウキャプチャではなく）で 透過を許可 にチェックが入っているか確認してください。

OBS に何も映らない

ゲームキャプチャのウィンドウに [VRCast.exe]: VRCast を選び直してください。VRCast を最小化すると映らないことがあります。

ドラッグ＆ドロップできない

VRCast を管理者として実行していると Windows の制限でドロップできません。通常どおり起動するか、ファイルを選ぶ... を使ってください。

ゲームや OBS と一緒に使うとトラッキングがカクつく

設定 タブの 軽量モード が ON になっているか確認してください（既定は ON）。MediaPipe ならトラッキングタブの トラッカーの動作 を エコ にすると負荷が半分ほどになります。それでも重いときは、使わない 腕・手 のトラッキングを OFF にすると負荷が下がります。プロセスの優先度 を「通常以上」にするのも効果があります。

口パクしない

顔 タブで正しいマイクが選ばれているか、音量 メーターが動くか確認し、 動かなければ マイク感度 を上げるか ノイズゲート を下げてください。

表情が変わらない

表情の反映は MediaPipe・iPhone・外部アプリ（VMC）・iFacialMocap のみ対応です。トラッキング タブで入力元がいずれかになっているか、 表情を反映 が ON か確認してください。反応しにくいときは 表情のしきい値 を下げ、 違う表情になるときは表情ごとの選択で使う表情を指定してください。

カメラが認識されない・トラッキングが動かない

まず トラッキング タブの カメラ で、お使いの Web カメラが選ばれているか確認してください。 VRCast Camera（VRCast の仮想カメラ）・OBS Virtual Camera などの仮想カメラや、顔認証用の赤外線（IR）カメラを選ぶと、映像は届いても顔が認識されません。

デバッグログ タブを開くと、カメラ一覧・トラッカーの状態と、起動してからのログを確認できます。 WARN / ERROR だけを表示したり、カテゴリを Tracker / TrackerOutput / Tracking（カメラ関係）に絞ったりできます。 不具合を報告するときは 表示中をコピー を押して、ログと環境をそのまま貼り付けてください。

原因がわからないときは 詳細ログ を ON にして、症状が出るまで待ってからコピーしてください。 受信の統計（1 秒あたりのデータ数、顔・腕・手が映っていた割合）や MediaPipe の推定にかかる時間などが DEBUG として記録されます。 設定は保存されるため、調べ終わったら OFF に戻してください。

設定ファイル・ログの場所

%USERPROFILE%\AppData\LocalLow\VRCast\VRCast\ （settings.json と Player.log）。不具合の報告時は Player.log を添えてください。
