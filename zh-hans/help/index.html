快速开始

VRCast 是一款单独显示 VRChat 虚拟形象并输出到 OBS 等直播软件的应用。 启动 VRCast 后，左侧面板会打开 开始 标签页，在画面上引导相同的步骤。

  1. 在 Unity 中将虚拟形象导出为 .vrcaster 文件
  2. 将 .vrcaster 文件拖放到 VRCast 窗口
  3. VRM（.vrm，如 VRoid）无需导出，直接拖放即可（关于 VRM）
  4. 点击 开始 标签页中的 设为透明
  5. 在 OBS 中添加 游戏采集 并勾选 允许透明
  6. 按 Tab 键隐藏操作面板

1. 导出虚拟形象（Unity）

在包含虚拟形象的 Unity 项目（用 VCC 创建的项目亦可，Unity 2022.3.22f1）中操作。

  1. 双击发布 zip 中 VRCast-Converter 文件夹（与主程序的 VRCast 文件夹分开）里的 VRCast-Converter-版本.unitypackage（或拖入 Unity），然后点击 Import（会放入 Assets/VRCast/Converter）。
  2. 打开菜单 VRCast > Avatar Exporter。
  3. 指定场景中的虚拟形象（最上层的父对象），点击 导出... 并选择保存位置。 界面会使用操作系统的语言（可在顶部的 语言 中切换）。

不会修改原始虚拟形象。表情、口型同步、眨眼、物理摆动和 Constraint 的设置也会一并导出。

场景中未激活（取消勾选）的对象及其子对象不会被导出。想要显示的服装和小物请先激活再导出。

BlendShape 会按 Unity 场景中设置的值导出（优先使用场景中的 BlendShape 值，默认开启）。 如果 FX 层会随服装切换驱动收缩用 BlendShape 等，关闭后会按进入 VRChat 时的初始状态值导出。

FX 层中的表情剪辑会自动导出。不在 FX 中的表情（例如旧虚拟形象附带的表情动画）， 可将动画剪辑或文件夹拖到导出窗口的 追加表情 中作为表情导出（仅限只驱动 BlendShape 的剪辑，按虚拟形象分别保存）。

如果场景中有该虚拟形象的 FaceEmo 设置，会自动以 FaceEmo 的模式名称导出其表情（即使未执行 FaceEmo 的“应用到虚拟形象”也可以；仅使用 BlendShape 部分，不含小物显示等）。

【测试版】用 Modular Avatar 等改造过的虚拟形象，直接指定即可按改造后的样子（合并的服装、添加的表情和开关）导出。 用 MA 的 Merge Armature / Bone Proxy 添加的服装和小物，即使未被合并，也会重新挂到虚拟形象的骨骼上并跟随身体。 用 MA 的 Blendshape Sync 跟随嘴部等的链条和小物，也会跟随口型同步、眨眼和追踪。 目前为临时支持，部分虚拟形象可能无法正确导出。

如需通过 Package Manager 安装，请在 Window > Package Manager 中点击 + > Add package from git URL...，输入 https://github.com/coffin299/VRCast.git?path=/Packages/com.vrcast.converter （需要 Git）。同时安装 unitypackage 和此包会出错，请只选其一。

2. 在 VRCast 中加载

  • 将 .vrcaster 或 .vrm 文件拖放到 VRCast 窗口即可加载。
  • 也可以使用 开始 标签页的 选择文件...， 或 虚拟形象 标签页的 浏览... 选择。
  • 上次加载的虚拟形象会在下次启动时自动加载。
  • 虚拟形象 标签页的 最近使用的虚拟形象 中最多列出 10 个最近使用的虚拟形象，点击即可切换。名称下方显示加入（拖放、浏览、加载）的时间（点击 × 后再点 移除 从列表移除）。 相机、灯光、虚拟形象亮度、待机姿势和身体朝向会按虚拟形象分别记住，切换时恢复。

只能加载 .vrcaster 和 .vrm 文件（不能加载图片或 unitypackage 等）。如果 .vrcaster 显示错误，请重新导出。

加载 VRM

  • VRM 0.x / 1.0 的 .vrm（如用 VRoid Studio 制作）无需在 Unity 中导出即可直接加载。
  • VRM 的表情（喜、怒、哀、乐、惊讶及自定义表情）、眨眼和单眼眨眼、A-I-U-E-O 口型以及摇摆骨骼（SpringBone）会用于 VRCast 的表情、自动眨眼、口型同步和摇摆效果。
  • 虚拟形象 标签页会显示 VRM 版本（0.x / 1.0）和作者。

不支持改变材质颜色的表情、VRM 的约束，以及没有眼睛骨骼的模型的视线（BlendShape 方式）。请遵守 VRM 中写明的使用条件。

3. 在 OBS 中显示

  1. 在 VRCast 的 开始 标签页（或 显示 标签页）中将背景设为 透明。 VRCast 窗口中仍显示背景色，但 OBS 中背景会被去除。
  2. 在 OBS 的 来源 中点击 +，添加 游戏采集。
  3. 模式选择 采集特定窗口，窗口选择 [VRCast.exe]: VRCast。
  4. 勾选 允许透明。
  5. 在 VRCast 中按 Tab 键隐藏操作面板（面板也会显示在 OBS 中）。隐藏期间即使透明为关闭，OBS 中背景也会透明。

窗口采集 不支持透明。需要透明背景时，请务必使用 游戏采集。

虚拟摄像头（Discord / Zoom 等）

  1. 在 输出 标签页中打开虚拟摄像头输出。
  2. 仅首次需要点击 安装驱动程序（会出现管理员确认）。
  3. 在要使用的应用中选择 VRCast Camera 作为摄像头（若未列出，请重启该应用）。

操作面板不会输出到虚拟摄像头。Discord 等无法显示透明，因此背景会以背景色显示。 移动或删除 VRCast 文件夹前，请先点击 卸载驱动程序。

输出标签页显示“已就绪”时，表示还没有应用打开摄像头（不是错误）。在接收端应用中选择 VRCast Camera 后会变为“正在发送”。

在 Discord 等中摄像头无法启动时（Windows 11）

  1. 在 输出 标签页中打开 使用 Windows 11 方式（Media Foundation）输出。
  2. 点击 安装驱动程序 注册此方式的驱动程序（每种方式一次，会出现管理员确认）。
  3. 在要使用的应用中选择 VRCast Camera (MF)。

它会被视为普通的 Windows 摄像头，因此在旧方式未列出或启动失败的应用中也可能可以使用。仅在 VRCast 运行且输出打开时才会列出。驱动程序会复制到 Program Files，移动 VRCast 文件夹后无需重新注册。

Spout2（轻量、保留透明地输出到 OBS）

  1. 为 OBS 安装 Spout2 插件。
  2. 在 输出 标签页的 Spout2 中打开 输出 (VRCast)。
  3. 在 OBS 中添加 Spout2 Capture 来源，并选择 VRCast 作为发送端。
  4. 若要背景透明，请在 VRCast 中打开 背景透明，并在 OBS 的 Spout2 Capture 来源属性中将 Composite mode 设为 Default（否则背景不会透明）。

画面在 GPU 上传递，因此比游戏捕获或虚拟摄像头更轻，透明背景也会原样传递。操作面板不会输出。分辨率与 VRCast 窗口大小相同。

外观与灯光（显示标签页）

项目 说明
相机 更改与重置视野。右键拖动旋转，中键拖动平移，滚轮缩放。相机位置和视野会按虚拟形象分别记住，重启后也会恢复。开启 锁定相机 后，鼠标拖动和滚轮不会再移动相机（仍可更改视野和重置）。
背景 背景色（默认米色）与透明切换。透明时 VRCast 窗口中仍显示背景色，但 OBS 游戏采集会去除背景。
分辨率 窗口大小（横向 / 纵向预设）。
灯光 环境光 会均匀照亮整个虚拟形象，阳光 从一个方向照射。 画面偏暗时，请点击 晴天 预设或调高环境光。阳光颜色 越低越偏暖色。 方向 为 0 时从正面照射。灯光无法变亮时，请调高 虚拟形象亮度。灯光和虚拟形象亮度会按虚拟形象分别记住。
轮廓线 粗细 可加粗或变细虚拟形象的轮廓线（lilToon / MToon / Poiyomi / UTS）（0～3，1 = 保持材质设置，0 = 无轮廓线）。点击 保持材质（1） 可恢复。按虚拟形象分别记住。

在 姿势·表情 标签页中可以更改虚拟形象的朝向、手臂姿势和表情。 可为每种表情分配快捷键（默认全部未分配）。点击按键按钮后按下要分配的键（也可使用 Ctrl+Alt+N 等组合键、小键盘（NumLock 开启时与数字键区分）、符号键、右 Ctrl 等单独按键（按下后松开）以及鼠标侧键），按 Esc 取消（不能使用 Tab）。旁边的 重置 可取消分配（按虚拟形象分别保存）。 开启 VRCast 在后台时也可使用（默认开启）后，操作 OBS 等时也能切换。在其他应用中输入时也会响应，建议与 Ctrl 或 Alt 组合使用。 通过按钮或快捷键选择的表情会被固定，不会被自动检测改变。再次选择同一表情或点击 恢复自动检测 即可恢复。 OSC / HTTP 标签页（输出与设置之间）会列出当前虚拟形象每个表情的命令（点击 复制 复制），端口下方显示 OSC 目标和 HTTP URL（点击 在浏览器中打开状态 测试；在 Stream Deck 中将完整 URL 设置到“网站”的“在后台发送 GET 请求”）。开启 外部操作（OSC / HTTP） 后，可从 Stream Deck 或 OSC 应用切换表情（仅限本机。例如 http://127.0.0.1:39571/expression?name=Smile&toggle=1、OSC /vrcast/expression "Smile"。编号 0 = 无表情，1 起 = 表情顺序）。

待机动作（默认开启，仅限 Humanoid）会在不使用摄像头时，稍微加上呼吸、身体摇摆和头部晃动，避免虚拟形象完全静止。 关闭 呼吸 · 身体摇摆 后会停止。开启时可以调整 呼吸、身体摇摆、头部晃动 的强度（0～2，1 为标准）和 速度（0.5～2 倍）。 面部追踪时会停止头部晃动，跟随本人的动作。

口型同步与眨眼（面部标签页）

  • 打开 用麦克风对口型 并选择麦克风，一边看 音量 表，一边调整 麦克风灵敏度 和 噪声门（低于此音量视为无声）。
  • 打开 根据元音改变口型 后，会像 VRChat 一样根据元音（A I U E O）改变口型。 判断不准时，请调整 音高校正（声音较高的人向右）。
  • 物理摆动（PhysBone 近似）和自动眨眼也可以开启或关闭。
  • 开启 表情期间不眨眼 后，显示表情期间会同时停止自动眨眼和面部追踪的眨眼，表情的眼睛形状不会被破坏。
  • 开启 物理摆动 / 眨眼 / 视线 中的 看向镜头 后，眼睛会看向画面（代替追踪的视线，关闭追踪时也有效）。也可用面板底部的按钮或快捷键（默认：小键盘 5，可在 设置 标签页更改）切换。
  • 开启 表情期间停止麦克风口型同步、表情期间停止追踪的嘴部动作 后，显示表情期间会停止相应的嘴部动作（可分别开启，也可同时开启；适用于表情的嘴型与口型同步重叠时会变形的虚拟形象）。
  • 在 形态键设置 标签页的 BlendShape 上限 中可为每个 BlendShape 设定可动到的最大值（100 = 不限制）。如果眨眼时眼睛消失、张嘴时脸部变形，请调低对应的 BlendShape。 在 对象 中选择 面部（眨眼、嘴、表情）（由眨眼、口型同步、表情、完美同步驱动的）或 其他（体型、服装等），并可用 搜索 缩小范围。设置按虚拟形象分别保存。不对追踪的表情应用上限（默认开启）开启时，由追踪标签页的 反映表情 切换的表情不受上限限制（手动选择的表情、眨眼、口型同步和完美同步仍受限制）。

摄像头追踪（追踪标签页）

  • 打开 启用追踪 后，内置追踪器会自动启动，驱动头部朝向、眨眼、嘴部和视线（MediaPipe 还包括手臂和手）。
  • 使用 MediaPipe 且 手臂 / 手 开启时，上半身扭转 / 倾斜（肩部）（默认开启）会根据双肩的朝向扭转或左右倾斜上半身。未拍到肩部时按头部位置倾斜。不想扭转时，开启 固定上半身扭转 即可只保留左右倾斜。在 原始数据显示 中可通过绿色方框和角度确认上半身朝向（骨架按虚拟形象的大小绘制，无需移动相机）。
  • 输入源 通过打开纵向排列的开关之一来选择。每行右侧（宽度不足时在开关下方）会显示推荐（MediaPipe）以及电脑负载参考（低 / 中 / 高）。MediaPipe 关闭 手臂 / 手 后会更轻，从 iPhone 等接收的输入源由手机进行追踪，因此电脑负载较低。
  • 关闭 追踪眨眼（默认开启）后，不再跟随眼睛开合，改用面部标签的自动眨眼（完美同步也不驱动眨眼）。
  • 如果闭上的眼睛或单眼眨眼与头部倾斜、手臂方向相反，请开启 动作 栏中的 交换面部左右（默认关闭）。只交换面部（眨眼、完美同步、视线），头部朝向和手臂仍按 镜像 设置。
  • 使用 MediaPipe、iPhone / 外部应用（VMC）或 iFacialMocap时，打开 反映表情（默认开启）后，会检测笑脸、惊讶、生气、悲伤、眨单眼、眯眼、嘟嘴并切换虚拟形象的表情（没有可分配表情的不会检测）。 可用每种表情的 阈值 调整反应程度（越低越容易反应，可参考 原始数据显示 中的表情数值），并为每种表情选择要使用的表情（自动 会根据表情名称推测）。
  • 使用 MediaPipe、iPhone / 外部应用（VMC）或 iFacialMocap时还支持 完美同步（默认开启）。如果虚拟形象带有 ARKit 名称的 BlendShape（eyeBlinkLeft、jawOpen、mouthSmileLeft 等），眉毛、脸颊和嘴形都会跟随面部动作。 可在 启用条件 中选择 20 种以上（默认）或 有 1 种即可，下方会显示找到的数量。完美同步期间，反映表情 的自动切换会暂停（少于 20 种时会同时使用）。
  • 用 < > 选择相机。没有反应时，请点击 重启追踪器。
  • 将输入源设为 iPhone / 外部应用（VMC，仅面部） 后，会代替相机，通过 VMC 协议从手机应用（如 iPhone 上的 Waidayo）接收面部动作。 请将电脑和手机连接到同一 Wi-Fi，并在应用的发送目标中输入追踪标签页显示的 此电脑的 IP 地址 和 UDP 端口（默认 39539）。 首次会弹出 Windows 防火墙确认，请允许专用网络。发送 ARKit 数值的应用还可使用完美同步和反映表情（手臂和手不会动）。
  • 将输入源设为 iFacialMocap（iPhone，仅面部） 后，会从 iPhone 上的 iFacialMocap 接收面部动作。 请将电脑和 iPhone 连接到同一 Wi-Fi，并在追踪标签页的 iPhone 的 IP 地址 中输入 iFacialMocap 屏幕上方显示的 IP 地址（使用 UDP 端口 49983）。 首次会弹出 Windows 防火墙确认，请允许专用网络。也可使用完美同步和反映表情（手臂和手不会动）。
  • 正面方向偏移时，请看着相机，点击面板底部 重置 中的 头部朝向（头部、上半身、视线）。只调整视线时点击 视线。
  • 开始追踪时（更改输入源或相机后也一样），头部静止约 0.5 秒时的朝向会自动成为正面。即使用手遮住脸等导致丢失，也不会重新设定正面。
  • 在 身体动作 中可以选择随头部动作倾斜上半身，或整体移动身体。

如果其他应用（Discord、Zoom、VSeeFace 等）正在使用摄像头，追踪器将无法启动。

设置与重置（设置标签页）

  • 显示语言：自动（跟随系统）/ English / 日本語 / 한국어 / 简体中文 / 繁體中文。也可以在任意标签页中用面板顶部的语言按钮切换。
  • 界面大小：75%～200%。
  • 主题：浅色（默认）/ 深色。如果未在显示标签页中更改背景色，背景也会随主题切换。
  • 低负载模式（默认开启）：将画面限制为 30fps（关闭时为 60fps），OpenSeeFace 使用较轻的模型，降低与游戏或 OBS 同时使用时的负载。MediaPipe 的负载请在追踪标签页的 追踪器模式 中选择。
  • 显示运行状态（默认开启）：在面板底部以英文显示画面 FPS、VRCast 的 CPU 使用率、GPU 处理时间、内置追踪器的 CPU 使用率和追踪接收速率（每秒更新）。可用于判断卡顿的原因。
  • 进程优先级（默认“正常”）：同时更改 VRCast 本体和内置追踪器的优先级（立即生效）。游戏时追踪卡顿可调高。设为“高”可能使其他应用变慢。
  • CPU 设置 › AMD（X3D）› 在没有 3D V-Cache 的核心上运行（默认开启；仅对 3D V-Cache 只位于一个 CCD 的 CPU 有效，如 7950X3D / 9950X3D，本机是否支持会显示在设置下方）：游戏运行时 Windows 会把应用集中到与游戏相同的核心上，此选项让 VRCast 本体和内置追踪器在另一侧核心上运行，避免与游戏争抢核心（立即生效）。如果 VRCast 本身被识别为游戏，请在 Game Bar（Win + G）设置中关闭“记住这是一个游戏”。
  • CPU 设置 › Intel（P 核 / E 核）› 使用的核心（默认“自动”；仅对具有 P 核和 E 核的 Intel CPU 有效，即第 12 代及以后、Core Ultra）：选择运行 VRCast 本体和内置追踪器的核心（立即生效）。仅 E 核 把 P 核让给游戏，但追踪和渲染可能变慢。仅 P 核 速度快，但会与游戏争抢核心。不确定时保持“自动”即可。
  • 渲染使用的 GPU（默认“自动”）：可选择自动 / 节能 / 高性能，或从列表中直接选择 GPU。重新启动 VRCast 后生效（立即重新启动 VRCast 按钮，无需重启电脑）。使用 OBS 捕获或虚拟摄像头时，与 OBS 使用同一 GPU 最省资源。内置追踪器在 CPU 上运行，不受此设置影响。
  • NVIDIA 即时重放（仅在有 NVIDIA GPU 的电脑上显示）：按下 不让 NVIDIA 即时重放检测 后，会在驱动设置中写入 VRCast 专用配置文件，使 VRCast 不被即时重放（ShadowPlay）识别为游戏。重新启动 VRCast 后生效。按 恢复 NVIDIA 即时重放的检测 可还原。这是非官方设置，部分驱动可能无效。如提示无法更改，请尝试以管理员身份运行 VRCast。
  • 更新：启动时检查是否有新版本，如有则在面板顶部提示（从 GitHub 下载 / 从 BOOTH 下载 / 查看更新日志（GitHub））。 仅为读取最新版本号而连接网站（coffin299.github.io），也可以关闭。
  • 设置会在 VRCast 退出时自动保存，并在下次启动时恢复。
  • 设置预设：按类别（运行优化、追踪、输出等）选择设置并导出为 .vrcastpreset 文件（导出...），可在其他电脑或之后导入（导入...，或将文件拖放到窗口）。导入时选择要应用的类别后按 应用。排除虚拟形象相关 可一次性去掉灯光、姿势、表情映射等按虚拟形象调整的设置。不包含各虚拟形象的记录（形态键、相机、表情按键）以及麦克风、摄像头、端口等各电脑的值。文件是文本，也可以删除不需要的类别后使用。

故障排除

虚拟形象偏暗

请点击 显示 标签页的 晴天 预设，或调高 环境光。 将 方向 设为 0 附近可从正面照射。 lilToon 等着色器的亮度上限为贴图颜色，因此调高阳光超过一定程度后不会再变亮。 此时请调高 虚拟形象亮度（0.1～10，1 = 保持材质原样）。

OBS 中背景不透明

请确认 VRCast 的背景已设为 透明，并且 OBS 使用的是 游戏采集（而非窗口采集）， 且已勾选 允许透明。

OBS 中什么都不显示

请在游戏采集的窗口中重新选择 [VRCast.exe]: VRCast。最小化 VRCast 可能会导致无法显示。

无法拖放

以管理员身份运行 VRCast 时，Windows 会阻止拖放。请正常启动，或使用 选择文件...。

与游戏或 OBS 同时使用时追踪卡顿

请确认 设置 标签页中的 低负载模式 已开启（默认开启）。使用 MediaPipe 时，将追踪标签页的 追踪器模式 设为 流畅 可降低负载，设为 节能 可再减半左右（默认的 丝滑（高负载） 为了让手指顺滑移动，负载较高）。仍然卡顿时，关闭不需要的手臂和手的追踪可以降低负载。将 进程优先级 设为“高于正常”也有帮助。

口型不动

请在 面部 标签页中确认选择了正确的麦克风，以及 音量 表是否有反应。 如果没有反应，请调高 麦克风灵敏度 或调低 噪声门。

表情不变化

表情反映仅支持 MediaPipe、iPhone / 外部应用（VMC）和 iFacialMocap。请在 追踪 标签页中确认输入源为其中之一， 且 反映表情 已开启。反应不灵敏时请调低 表情阈值； 出现错误的表情时，请为每种表情指定要使用的表情。

无法识别摄像头·追踪不工作

请先在 追踪 标签页的 相机 中确认选择的是您的网络摄像头。 如果选择了 VRCast Camera（VRCast 的虚拟摄像头）、OBS Virtual Camera 等虚拟摄像头，或用于人脸登录的红外（IR）摄像头，即使有画面也无法识别面部。

打开 调试日志 标签页，可以查看摄像头列表、追踪器状态以及启动以来的日志。 可以只显示 WARN / ERROR，或将类别限定为 Tracker / TrackerOutput / Tracking（与摄像头相关）。 报告问题时，请点击 复制显示内容，然后直接粘贴日志和环境信息。

原因不明时，请开启 详细日志，等到问题出现后再复制。 接收统计（每秒数据量、面部·手臂·手被拍到的比例）和 MediaPipe 的推理耗时等会作为 DEBUG 记录。 该设置会被保存，排查结束后请关闭。

设置文件与日志的位置

%USERPROFILE%\AppData\LocalLow\VRCast\VRCast\ （settings.json 和 Player.log）。报告问题时请附上 Player.log。
