VRCast 書き出しツール / VRCast Exporter
=======================================

[日本語]

このフォルダの VRCast-Converter-(バージョン).unitypackage は、VRChat アバターの Unity プロジェクトにインポートするものです。
VRCast 本体（VRCast フォルダ）に入れるものではありません。

1. VCC からアバターの入ったプロジェクトを開きます。
2. VRCast-Converter-(バージョン).unitypackage をダブルクリック（または Unity にドラッグ＆ドロップ）して「Import」を押します。
3. メニュー「VRCast」→「Avatar Exporter」で、シーン上のアバターを指定して「書き出す...」で .vrcaster を保存します。
4. 保存した .vrcaster を VRCast のウィンドウにドラッグ＆ドロップします。

新しいバージョンに更新するときは、同じ手順でインポートし直してください（上書きされます）。
不要になったら、プロジェクトの Assets/VRCast/Converter フォルダを削除してください。
詳しくは VRCast フォルダの README.txt と、ヘルプ（https://coffin299.github.io/VRCast/help/）をご覧ください。


[English]

VRCast-Converter-(version).unitypackage in this folder is imported into your VRChat avatar's Unity project.
It does not go into the VRCast app (the VRCast folder).

1. Open the project with your avatar from VCC.
2. Double-click VRCast-Converter-(version).unitypackage (or drag it into Unity) and click "Import".
3. Open "VRCast" > "Avatar Exporter", pick your avatar in the scene and click "Export..." to save a .vrcaster file.
4. Drag and drop the saved .vrcaster file onto the VRCast window.

To update, import the new version the same way (it overwrites the old one).
To remove it, delete the Assets/VRCast/Converter folder in your project.
See README.txt in the VRCast folder and the help page (https://coffin299.github.io/VRCast/help/) for details.
