快速開始

VRCast 是一款單獨顯示 VRChat 虛擬形象並輸出到 OBS 等直播軟體的應用程式。 啟動 VRCast 後，左側面板會開啟 開始 分頁，在畫面上引導相同的步驟。

  1. 在 Unity 中將虛擬形象匯出為 .vrcaster 檔案
  2. 將 .vrcaster 檔案拖放到 VRCast 視窗
  3. VRM（.vrm，如 VRoid）無需匯出，直接拖放即可（關於 VRM）
  4. 點擊 開始 分頁中的 設為透明
  5. 在 OBS 中新增 遊戲擷取 並勾選 允許透明
  6. 按 Tab 鍵隱藏操作面板

1. 匯出虛擬形象（Unity）

在包含虛擬形象的 Unity 專案（用 VCC 建立的專案亦可，Unity 2022.3.22f1）中操作。

  1. 雙擊發佈 zip 中 VRCast-Converter 資料夾（與主程式的 VRCast 資料夾分開）裡的 VRCast-Converter-版本.unitypackage（或拖入 Unity），然後點擊 Import（會放入 Assets/VRCast/Converter）。
  2. 開啟選單 VRCast > Avatar Exporter。
  3. 指定場景中的虛擬形象（最上層的父物件），點擊 匯出... 並選擇儲存位置。 介面會使用作業系統的語言（可在頂部的 語言 中切換）。

不會修改原始虛擬形象。表情、口型同步、眨眼、物理擺動和 Constraint 的設定也會一併匯出。

場景中未啟用（取消勾選）的物件及其子物件不會被匯出。想要顯示的服裝和小物請先啟用再匯出。

BlendShape 會按 Unity 場景中設定的值匯出（優先使用場景中的 BlendShape 值，預設開啟）。 如果 FX 層會隨服裝切換驅動收縮用 BlendShape 等，關閉後會按進入 VRChat 時的初始狀態值匯出。

FX 層中的表情剪輯會自動匯出。不在 FX 中的表情（例如舊虛擬形象附帶的表情動畫）， 可將動畫剪輯或資料夾拖到匯出視窗的 追加表情 中作為表情匯出（僅限只驅動 BlendShape 的剪輯，按虛擬形象分別儲存）。

如果場景中有該虛擬形象的 FaceEmo 設定，會自動以 FaceEmo 的模式名稱匯出其表情（即使未執行 FaceEmo 的「套用到虛擬形象」也可以；僅使用 BlendShape 部分，不含小物顯示等）。

【測試版】用 Modular Avatar 等改造過的虛擬形象，直接指定即可按改造後的樣子（合併的服裝、新增的表情和開關）匯出。 用 MA 的 Merge Armature / Bone Proxy 新增的服裝和小物，即使未被合併，也會重新掛到虛擬形象的骨骼上並跟隨身體。 用 MA 的 Blendshape Sync 跟隨嘴部等的鏈條和小物，也會跟隨口型同步、眨眼和追蹤。 目前為暫時支援，部分虛擬形象可能無法正確匯出。

如需透過 Package Manager 安裝，請在 Window > Package Manager 中點擊 + > Add package from git URL...，輸入 https://github.com/coffin299/VRCast.git?path=/Packages/com.vrcast.converter （需要 Git）。同時安裝 unitypackage 和此套件會出錯，請只選其一。

2. 在 VRCast 中載入

  • 將 .vrcaster 或 .vrm 檔案拖放到 VRCast 視窗即可載入。
  • 也可以使用 開始 分頁的 選擇檔案...， 或 虛擬形象 分頁的 瀏覽... 選擇。
  • 上次載入的虛擬形象會在下次啟動時自動載入。
  • 虛擬形象 分頁的 最近使用的虛擬形象 中最多列出 10 個最近使用的虛擬形象，點擊即可切換（點擊 × 後再點 移除 從清單移除）。 相機、燈光、虛擬形象亮度、待機姿勢和身體朝向會依虛擬形象分別記住，切換時恢復。

只能載入 .vrcaster 和 .vrm 檔案（不能載入圖片或 unitypackage 等）。如果 .vrcaster 顯示錯誤，請重新匯出。

載入 VRM

  • VRM 0.x / 1.0 的 .vrm（如用 VRoid Studio 製作）無需在 Unity 中匯出即可直接載入。
  • VRM 的表情（喜、怒、哀、樂、驚訝及自訂表情）、眨眼和單眼眨眼、A-I-U-E-O 口型以及搖擺骨骼（SpringBone）會用於 VRCast 的表情、自動眨眼、口型同步和搖擺效果。
  • 虛擬形象 分頁會顯示 VRM 版本（0.x / 1.0）和作者。

不支援改變材質顏色的表情、VRM 的約束，以及沒有眼睛骨骼的模型的視線（BlendShape 方式）。請遵守 VRM 中寫明的使用條件。

3. 在 OBS 中顯示

  1. 在 VRCast 的 開始 分頁（或 顯示 分頁）中將背景設為 透明。 VRCast 視窗中仍顯示背景色，但 OBS 中背景會被去除。
  2. 在 OBS 的 來源 中點擊 +，新增 遊戲擷取。
  3. 模式選擇 擷取特定視窗，視窗選擇 [VRCast.exe]: VRCast。
  4. 勾選 允許透明。
  5. 在 VRCast 中按 Tab 鍵隱藏操作面板（面板也會顯示在 OBS 中）。隱藏期間即使透明為關閉，OBS 中背景也會透明。

視窗擷取 不支援透明。需要透明背景時，請務必使用 遊戲擷取。

虛擬攝影機（Discord / Zoom 等）

  1. 在 輸出 分頁中開啟虛擬攝影機輸出。
  2. 僅首次需要點擊 安裝驅動程式（會出現系統管理員確認）。
  3. 在要使用的應用程式中選擇 VRCast Camera 作為攝影機（若未列出，請重新啟動該應用程式）。

操作面板不會輸出到虛擬攝影機。Discord 等無法顯示透明，因此背景會以背景色顯示。 移動或刪除 VRCast 資料夾前，請先點擊 解除安裝驅動程式。

輸出分頁顯示「已就緒」時，表示還沒有應用程式開啟攝影機（不是錯誤）。在接收端應用程式中選擇 VRCast Camera 後會變為「正在傳送」。

在 Discord 等中攝影機無法啟動時（Windows 11）

  1. 在 輸出 分頁中開啟 使用 Windows 11 方式（Media Foundation）輸出。
  2. 點擊 安裝驅動程式 註冊此方式的驅動程式（每種方式一次，會出現系統管理員確認）。
  3. 在要使用的應用程式中選擇 VRCast Camera (MF)。

它會被視為一般的 Windows 攝影機，因此在舊方式未列出或啟動失敗的應用程式中也可能可以使用。僅在 VRCast 執行中且輸出開啟時才會列出。驅動程式會複製到 Program Files，移動 VRCast 資料夾後無需重新註冊。

Spout2（輕量、保留透明地輸出到 OBS）

  1. 為 OBS 安裝 Spout2 外掛。
  2. 在 輸出 分頁的 Spout2 中開啟 輸出 (VRCast)。
  3. 在 OBS 中新增 Spout2 Capture 來源，並選擇 VRCast 作為傳送端。
  4. 若要背景透明，請在 VRCast 中開啟 背景透明，並在 OBS 的 Spout2 Capture 來源屬性中將 Composite mode 設為 Default（否則背景不會透明）。

畫面在 GPU 上傳遞，因此比遊戲擷取或虛擬攝影機更輕，透明背景也會原樣傳遞。操作面板不會輸出。解析度與 VRCast 視窗大小相同。

外觀與燈光（顯示分頁）

項目 說明
相機 變更與重設視野。右鍵拖曳旋轉，中鍵拖曳平移，滾輪縮放。相機位置和視野會依虛擬形象分別記住，重新啟動後也會恢復。開啟 鎖定相機 後，滑鼠拖曳和滾輪不會再移動相機（仍可變更視野和重設）。
背景 背景色（預設米色）與透明切換。透明時 VRCast 視窗中仍顯示背景色，但 OBS 遊戲擷取會去除背景。
解析度 視窗大小（橫向 / 直向預設）。
燈光 環境光 會均勻照亮整個虛擬形象，陽光 從一個方向照射。 畫面偏暗時，請點擊 晴天 預設或調高環境光。陽光顏色 越低越偏暖色。 方向 為 0 時從正面照射。燈光無法變亮時，請調高 虛擬形象亮度。燈光和虛擬形象亮度會依虛擬形象分別記住。

在 姿勢·表情 分頁中可以變更虛擬形象的朝向、手臂姿勢和表情。 可為每種表情分配快捷鍵（預設全部未分配）。點擊按鍵按鈕後按下要分配的鍵（也可使用 Ctrl+Alt+N 等組合鍵、數字鍵台（NumLock 開啟時與數字鍵區分）、符號鍵、右 Ctrl 等單獨按鍵（按下後放開）以及滑鼠側鍵），按 Esc 取消（不能使用 Tab）。旁邊的 重設 可取消分配（依虛擬形象分別儲存）。 開啟 VRCast 在背景時也可使用（預設開啟）後，操作 OBS 等時也能切換。在其他應用程式中輸入時也會回應，建議與 Ctrl 或 Alt 組合使用。 透過按鈕或快捷鍵選擇的表情會被固定，不會被自動偵測改變。再次選擇同一表情或點擊 恢復自動偵測 即可恢復。 OSC / HTTP 分頁（輸出與設定之間）會列出目前虛擬形象每個表情的命令（點擊 複製 複製），連接埠下方顯示 OSC 目標和 HTTP URL（點擊 在瀏覽器中開啟狀態 測試；在 Stream Deck 中將完整 URL 設定到「網站」的「在背景傳送 GET 請求」）。開啟 外部操作（OSC / HTTP） 後，可從 Stream Deck 或 OSC 應用程式切換表情（僅限本機。例如 http://127.0.0.1:39571/expression?name=Smile&toggle=1、OSC /vrcast/expression "Smile"。編號 0 = 無表情，1 起 = 表情順序）。

待機動作（預設開啟，僅限 Humanoid）會在不使用攝影機時，稍微加上呼吸、身體搖擺和頭部晃動，避免虛擬形象完全靜止。 關閉 呼吸 · 身體搖擺 後會停止。開啟時可以調整 呼吸、身體搖擺、頭部晃動 的強度（0～2，1 為標準）和 速度（0.5～2 倍）。 臉部追蹤時會停止頭部晃動，跟隨本人的動作。

口型同步與眨眼（臉部分頁）

  • 開啟 用麥克風對嘴型 並選擇麥克風，一邊看 音量 表，一邊調整 麥克風靈敏度 和 噪音閘（低於此音量視為無聲）。
  • 開啟 依母音改變嘴型 後，會像 VRChat 一樣依母音（A I U E O）改變嘴型。 判斷不準時，請調整 音高校正（聲音較高的人向右）。
  • 物理擺動（PhysBone 近似）和自動眨眼也可以開啟或關閉。
  • 開啟 表情期間不眨眼 後，顯示表情期間會同時停止自動眨眼和臉部追蹤的眨眼，表情的眼睛形狀不會被破壞。
  • 開啟 物理擺動 / 眨眼 / 視線 中的 看向鏡頭 後，眼睛會看向畫面（代替追蹤的視線，關閉追蹤時也有效）。也可用面板底部的按鈕或快捷鍵（預設：數字鍵台 5，可在 設定 分頁變更）切換。
  • 開啟 表情期間停止麥克風口型同步、表情期間停止追蹤的嘴部動作 後，顯示表情期間會停止相應的嘴部動作（可分別開啟，也可同時開啟；適用於表情的嘴型與口型同步重疊時會變形的虛擬形象）。
  • 在 形態鍵設定 分頁的 BlendShape 上限 中可為每個 BlendShape 設定可動到的最大值（100 = 不限制）。如果眨眼時眼睛消失、張嘴時臉部變形，請調低對應的 BlendShape。 在 對象 中選擇 臉部（眨眼、嘴、表情）（由眨眼、口型同步、表情、完美同步驅動的）或 其他（體型、服裝等），並可用 搜尋 縮小範圍。設定依虛擬形象分別儲存。

網路攝影機追蹤（追蹤分頁）

  • 開啟 啟用追蹤 後，內建追蹤器會自動啟動，驅動頭部朝向、眨眼、嘴部和視線（MediaPipe 還包括手臂和手）。
  • 使用 MediaPipe 且 手臂 / 手 開啟時，上半身扭轉 / 傾斜（肩部）（預設開啟）會依雙肩的朝向扭轉或左右傾斜上半身。未拍到肩部時依頭部位置傾斜。不想扭轉時，開啟 固定上半身扭轉 即可只保留左右傾斜。在 原始資料顯示 中可透過綠色方框和角度確認上半身朝向（骨架依虛擬形象的大小繪製，不需移動相機）。
  • 輸入來源 透過開啟縱向排列的開關之一來選擇。每列右側（寬度不足時在開關下方）會顯示推薦（MediaPipe）以及電腦負載參考（低 / 中 / 高）。MediaPipe 關閉 手臂 / 手 後會更輕，從 iPhone 等接收的輸入來源由手機進行追蹤，因此電腦負載較低。
  • 關閉 追蹤眨眼（預設開啟）後，不再跟隨眼睛開合，改用臉部分頁的自動眨眼（完美同步也不驅動眨眼）。
  • 如果閉上的眼睛或單眼眨眼與頭部傾斜、手臂方向相反，請開啟 動作 欄中的 交換臉部左右（預設關閉）。只交換臉部（眨眼、完美同步、視線），頭部朝向和手臂仍依 鏡像 設定。
  • 使用 MediaPipe、iPhone / 外部應用程式（VMC）或 iFacialMocap時，開啟 反映表情（預設開啟）後，會偵測笑臉、驚訝、生氣、悲傷、眨單眼、瞇眼、嘟嘴並切換虛擬形象的表情（沒有可分配表情的不會偵測）。 可用每種表情的 閾值 調整反應程度（越低越容易反應，可參考 原始資料顯示 中的表情數值），並為每種表情選擇要使用的表情（自動 會依表情名稱推測）。
  • 使用 MediaPipe、iPhone / 外部應用程式（VMC）或 iFacialMocap時還支援 完美同步（預設開啟）。如果虛擬形象帶有 ARKit 名稱的 BlendShape（eyeBlinkLeft、jawOpen、mouthSmileLeft 等），眉毛、臉頰和嘴形都會跟隨臉部動作。 可在 啟用條件 中選擇 20 種以上（預設）或 有 1 種即可，下方會顯示找到的數量。完美同步期間，反映表情 的自動切換會暫停（少於 20 種時會同時使用）。
  • 用 < > 選擇相機。沒有反應時，請點擊 重新啟動追蹤器。
  • 將輸入來源設為 iPhone / 外部應用程式（VMC，僅臉部） 後，會代替相機，透過 VMC 協定從手機應用程式（如 iPhone 上的 Waidayo）接收臉部動作。 請將電腦和手機連接到同一 Wi-Fi，並在應用程式的傳送目標中輸入追蹤分頁顯示的 此電腦的 IP 位址 和 UDP 連接埠（預設 39539）。 首次會跳出 Windows 防火牆確認，請允許私人網路。傳送 ARKit 數值的應用程式還可使用完美同步和反映表情（手臂和手不會動）。
  • 將輸入來源設為 iFacialMocap（iPhone，僅臉部） 後，會從 iPhone 上的 iFacialMocap 接收臉部動作。 請將電腦和 iPhone 連接到同一 Wi-Fi，並在追蹤分頁的 iPhone 的 IP 位址 中輸入 iFacialMocap 畫面上方顯示的 IP 位址（使用 UDP 連接埠 49983）。 首次會跳出 Windows 防火牆確認，請允許私人網路。也可使用完美同步和反映表情（手臂和手不會動）。
  • 正面方向偏移時，請看著相機，點擊面板底部 重設 中的 頭部朝向（頭部、上半身、視線）。只調整視線時點擊 視線。
  • 開始追蹤時（變更輸入來源或相機後也一樣），頭部靜止約 0.5 秒時的朝向會自動成為正面。即使用手遮住臉等導致遺失，也不會重新設定正面。
  • 在 身體動作 中可以選擇隨頭部動作傾斜上半身，或整體移動身體。

如果其他應用程式（Discord、Zoom、VSeeFace 等）正在使用網路攝影機，追蹤器將無法啟動。

設定與重設（設定分頁）

  • 顯示語言：自動（跟隨系統）/ English / 日本語 / 한국어 / 简体中文 / 繁體中文。也可以在任意分頁中用面板頂部的語言按鈕切換。
  • 介面大小：75%～200%。
  • 主題：淺色（預設）/ 深色。若未在顯示分頁中變更背景色，背景也會隨主題切換。
  • 低負載模式（預設開啟）：將畫面限制為 30fps（關閉時為 60fps），OpenSeeFace 使用較輕的模型，降低與遊戲或 OBS 同時使用時的負載。MediaPipe 的負載請在追蹤分頁的 追蹤器模式 中選擇。
  • 顯示執行狀態（預設開啟）：在面板底部以英文顯示畫面 FPS、VRCast 的 CPU 使用率、GPU 處理時間、內建追蹤器的 CPU 使用率和追蹤接收速率（每秒更新）。可用於判斷卡頓的原因。
  • 處理程序優先順序（預設「正常」）：同時變更 VRCast 本體和內建追蹤器的優先順序（立即生效）。遊戲時追蹤卡頓可調高。設為「高」可能使其他應用程式變慢。
  • CPU 設定 › AMD（X3D）› 在沒有 3D V-Cache 的核心上執行（預設開啟；僅對 3D V-Cache 只位於一個 CCD 的 CPU 有效，如 7950X3D / 9950X3D，本機是否支援會顯示在設定下方）：遊戲執行時 Windows 會把應用程式集中到與遊戲相同的核心上，此選項讓 VRCast 本體和內建追蹤器在另一側核心上執行，避免與遊戲爭搶核心（立即生效）。如果 VRCast 本身被視為遊戲，請在 Game Bar（Win + G）設定中關閉「記住這是遊戲」。
  • CPU 設定 › Intel（P 核 / E 核）› 使用的核心（預設「自動」；僅對具有 P 核和 E 核的 Intel CPU 有效，即第 12 代及以後、Core Ultra）：選擇執行 VRCast 本體和內建追蹤器的核心（立即生效）。僅 E 核 把 P 核讓給遊戲，但追蹤和繪製可能變慢。僅 P 核 速度快，但會與遊戲爭搶核心。不確定時保持「自動」即可。
  • 繪製使用的 GPU（預設「自動」）：可選擇自動 / 省電 / 高效能，或從清單中直接選擇 GPU。重新啟動 VRCast 後生效（立即重新啟動 VRCast 按鈕，不需要重新啟動電腦）。使用 OBS 擷取或虛擬攝影機時，與 OBS 使用同一 GPU 最省資源。內建追蹤器在 CPU 上執行，不受此設定影響。
  • NVIDIA 即時重播（僅在有 NVIDIA GPU 的電腦上顯示）：按下 不讓 NVIDIA 即時重播偵測 後，會在驅動程式設定中寫入 VRCast 專用設定檔，使 VRCast 不被即時重播（ShadowPlay）視為遊戲。重新啟動 VRCast 後生效。按 還原 NVIDIA 即時重播的偵測 可還原。這是非官方設定，部分驅動程式可能無效。如提示無法變更，請嘗試以系統管理員身分執行 VRCast。
  • 更新：啟動時檢查是否有新版本，如有則在面板頂部提示（從 GitHub 下載 / 從 BOOTH 下載 / 查看更新紀錄（GitHub））。 僅為讀取最新版本號而連線網站（coffin299.github.io），也可以關閉。
  • 設定會在 VRCast 結束時自動儲存，並在下次啟動時還原。
  • 開發者、協力者和授權條款可在 致謝 分頁中查看。 也可以在這裡開啟開發者的 Twitch 頻道。追隨或使用 Prime 訂閱會成為開發的動力。

點擊 重設所有設定（紅色按鈕），再在確認中點擊 確定重設，所有設定將恢復為預設值 （視窗大小和上次開啟的虛擬形象會保留）。此操作無法復原。

疑難排解

虛擬形象偏暗

請點擊 顯示 分頁的 晴天 預設，或調高 環境光。 將 方向 設為 0 附近可從正面照射。 lilToon 等著色器的亮度上限為貼圖顏色，因此調高陽光超過一定程度後不會再變亮。 此時請調高 虛擬形象亮度（0.1～10，1 = 保持材質原樣）。

OBS 中背景不透明

請確認 VRCast 的背景已設為 透明，並且 OBS 使用的是 遊戲擷取（而非視窗擷取）， 且已勾選 允許透明。

OBS 中什麼都不顯示

請在遊戲擷取的視窗中重新選擇 [VRCast.exe]: VRCast。最小化 VRCast 可能會導致無法顯示。

無法拖放

以系統管理員身分執行 VRCast 時，Windows 會阻止拖放。請正常啟動，或使用 選擇檔案...。

與遊戲或 OBS 同時使用時追蹤卡頓

請確認 設定 分頁中的 低負載模式 已開啟（預設開啟）。使用 MediaPipe 時，將追蹤分頁的 追蹤器模式 設為 流暢 可降低負載，設為 節能 可再減半左右（預設的 絲滑（高負載） 為了讓手指順滑移動，負載較高）。仍然卡頓時，關閉不需要的手臂和手的追蹤可以降低負載。將 處理程序優先順序 設為「高於正常」也有幫助。

嘴型不動

請在 臉部 分頁中確認選擇了正確的麥克風，以及 音量 表是否有反應。 如果沒有反應，請調高 麥克風靈敏度 或調低 噪音閘。

表情不變化

表情反映僅支援 MediaPipe、iPhone / 外部應用程式（VMC）和 iFacialMocap。請在 追蹤 分頁中確認輸入來源為其中之一， 且 反映表情 已開啟。反應不靈敏時請調低 表情閾值； 出現錯誤的表情時，請為每種表情指定要使用的表情。

無法辨識攝影機·追蹤不運作

請先在 追蹤 分頁的 相機 中確認選擇的是您的網路攝影機。 如果選擇了 VRCast Camera（VRCast 的虛擬攝影機）、OBS Virtual Camera 等虛擬攝影機，或用於臉部登入的紅外線（IR）攝影機，即使有畫面也無法辨識臉部。

開啟 偵錯日誌 分頁，可以查看攝影機清單、追蹤器狀態以及啟動以來的日誌。 可以只顯示 WARN / ERROR，或將類別限定為 Tracker / TrackerOutput / Tracking（與攝影機相關）。 回報問題時，請點擊 複製顯示內容，然後直接貼上日誌和環境資訊。

原因不明時，請開啟 詳細日誌，等到問題出現後再複製。 接收統計（每秒資料量、臉部·手臂·手被拍到的比例）和 MediaPipe 的推論耗時等會作為 DEBUG 記錄。 該設定會被儲存，排查結束後請關閉。

設定檔與記錄檔的位置

%USERPROFILE%\AppData\LocalLow\VRCast\VRCast\ （settings.json 和 Player.log）。回報問題時請附上 Player.log。
