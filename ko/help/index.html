빠른 시작

VRCast는 VRChat용 아바타를 단독으로 표시하고 OBS 같은 방송 소프트웨어에 보내는 앱입니다. VRCast를 실행하면 왼쪽 패널에 시작하기 탭이 열리고, 같은 단계를 화면에서 안내합니다.

  1. Unity에서 아바타를 .vrcaster 파일로 내보내기
  2. .vrcaster 파일을 VRCast 창에 드래그 앤 드롭
  3. VRM(.vrm, VRoid 등)은 내보낼 필요 없이 그대로 드래그 앤 드롭 (VRM에 대해)
  4. 시작하기 탭의 투명하게 하기를 누르기
  5. OBS에서 게임 캡처를 추가하고 투명도 허용에 체크
  6. Tab 키로 조작 패널 숨기기

1. 아바타 내보내기 (Unity)

아바타가 들어 있는 Unity 프로젝트 (VCC로 만든 프로젝트도 가능, Unity 2022.3.22f1)에서 작업합니다.

  1. 배포 zip(Jinxxy의 설치 버전은 압축을 푼 위치)의 VRCast-Converter 폴더(본체 VRCast 폴더와 별도)에 있는 VRCast-Converter-버전.unitypackage를 더블 클릭 (또는 Unity에 드래그 앤 드롭)하고 Import를 누릅니다 (Assets/VRCast/Converter에 들어갑니다).
  2. 메뉴 VRCast > Avatar Exporter를 엽니다.
  3. 씬의 아바타 (가장 위의 부모 오브젝트)를 지정하고 내보내기...를 눌러 저장 위치를 선택합니다. 화면은 OS 언어로 표시됩니다 (위쪽의 언어에서 전환 가능).

원본 아바타는 변경되지 않습니다. 표정·립싱크·눈 깜빡임·흔들림·Constraint 설정도 함께 내보내집니다.

비활성 오브젝트도 내보내기(기본 켜짐)가 켜져 있으면 씬에서 비활성(체크 해제)인 오브젝트도 꺼진 상태로 내보내집니다. VRCast의 오브젝트 탭에서 언제든 켤 수 있으므로 내보내기 전에 켤 필요가 없습니다 (파일이 커집니다). 끄면 비활성 오브젝트는 자식을 포함해 내보내지지 않습니다 (파티클 제외).

블렌드셰이프는 Unity 씬에서 설정한 값 그대로 내보내집니다 (씬의 블렌드셰이프 값을 우선, 기본 ON). 의상 전환에 맞춰 축소용 블렌드셰이프를 FX로 움직이는 경우 등에는 OFF로 하면 VRChat에 들어갔을 때의 초기 상태 값으로 내보냅니다.

FX 레이어에 있는 표정 클립은 자동으로 내보내집니다. FX에 없는 표정(예전 아바타에 포함된 표정 애니메이션 등)은 내보내기 화면의 추가 표정에 애니메이션 클립이나 폴더를 드래그하면 표정으로 내보낼 수 있습니다 (블렌드셰이프만 움직이는 클립이 대상, 아바타별로 저장).

씬에 FaceEmo 설정이 있으면 그 아바타의 표정을 FaceEmo의 모드 이름으로 자동으로 내보냅니다 (FaceEmo의 「아바타에 적용」을 하지 않아도 됩니다. 소품 표시 등은 제외하고 블렌드셰이프 부분만 사용합니다).

[베타] VRCFury, Modular Avatar 등으로 개조한 아바타는 그대로 지정하면 개조 후의 모습 (의상 통합·추가한 표정과 토글)으로 내보내집니다. MA의 Merge Armature / Bone Proxy로 붙인 의상·소품은 통합되지 않은 경우에도 아바타의 본에 다시 붙여 몸을 따라가게 합니다. MA의 Blendshape Sync로 입 등에 따라가게 한 체인·소품도 립싱크·눈 깜빡임·트래킹을 따라갑니다. 임시 지원이므로 올바르게 내보내지지 않을 수 있습니다.

Package Manager로 설치하려면 Window > Package Manager의 + > Add package from git URL...에 https://github.com/coffin299/VRCast.git?path=/Packages/com.vrcast.converter 를 입력합니다 (Git 필요). unitypackage와 둘 다 설치하면 오류가 나므로 한쪽만 사용하세요.

2. VRCast에서 불러오기

  • .vrcaster 또는 .vrm 파일을 VRCast 창에 드래그 앤 드롭하면 불러옵니다.
  • 또는 시작하기 탭의 파일 선택..., 아바타 탭의 찾아보기...로 선택할 수 있습니다.
  • 마지막으로 불러온 아바타는 다음 실행 시 자동으로 불러옵니다.
  • 아바타 탭의 최근 사용한 아바타에 최근 사용한 아바타가 최대 10개 표시되며, 클릭하여 전환할 수 있습니다. 이름 아래에는 넣은 (드롭·찾아보기·불러오기) 날짜가 표시됩니다 (×를 누른 뒤 제거로 목록에서 제거). 카메라·조명·아바타 밝기·대기 포즈·몸 방향은 아바타마다 기억되어 전환하면 복원됩니다.
  • 목록은 아바타마다 이미지가 있는 타일로 표시됩니다. 타일의 이미지로 PNG / JPG / GIF(GIF는 애니메이션됩니다)를 설정할 수 있습니다. 표시 중인 아바타는 이미지를 창에 드롭해도 설정됩니다. 제거하려면 상태의 이미지 제거를 누르세요. 이미지가 없는 아바타는 불러올 때 얼굴을 자동으로 촬영해 목록 이미지로 사용합니다. 상태의 얼굴 촬영으로 다시 찍을 수 있습니다.

.vrcaster와 .vrm 이외의 파일 (이미지나 unitypackage 등)은 불러올 수 없습니다. .vrcaster에서 오류가 표시되면 다시 내보내세요.

VRM 불러오기

  • VRM 0.x / 1.0의 .vrm(VRoid Studio 등으로 만든 것)은 Unity에서 내보내지 않고 그대로 불러올 수 있습니다.
  • VRM의 표정(기쁨·분노·슬픔·편안·놀람·사용자 표정), 눈 깜빡임·윙크, 아이우에오 입 모양, 흔들림(SpringBone)을 VRCast의 표정·자동 눈 깜빡임·립싱크·흔들림으로 사용합니다.
  • 아바타 탭에 VRM 버전(0.x / 1.0)과 제작자가 표시됩니다.

머티리얼 색을 바꾸는 표정, VRM의 컨스트레인트, 눈 본이 없는 모델의 시선(BlendShape 방식)은 반영되지 않습니다. VRM에 적힌 이용 조건을 지켜 사용하세요.

3. OBS에 표시하기

  1. VRCast의 시작하기 탭 (또는 그래픽 탭)에서 배경을 투명하게 합니다. VRCast 창에서는 배경색이 그대로 보이지만, OBS에서는 배경이 투명해집니다.
  2. OBS의 소스 아래 +를 눌러 게임 캡처를 추가합니다.
  3. 모드를 특정 창 캡처, 창을 [VRCast.exe]: VRCast로 설정합니다.
  4. 투명도 허용에 체크합니다.
  5. VRCast에서 Tab 키를 눌러 조작 패널을 숨깁니다 (패널도 OBS에 표시되기 때문). 숨긴 동안에는 투명이 꺼져 있어도 OBS에서 배경이 투명해집니다.

윈도우 캡처는 투명을 지원하지 않습니다. 투명하게 하려면 반드시 게임 캡처를 사용하세요.

가상 카메라 (Discord / Zoom 등)

  1. 출력 탭에서 가상 카메라 출력을 켭니다.
  2. 처음 한 번만 드라이버 등록을 누릅니다 (관리자 확인이 표시됩니다).
  3. 사용할 앱의 카메라 선택에서 VRCast Camera를 선택합니다 (없으면 그 앱을 다시 시작).

조작 패널은 가상 카메라에 표시되지 않습니다. Discord 등은 투명을 표시할 수 없으므로 배경은 배경색으로 표시됩니다. VRCast 폴더를 이동·삭제하기 전에 드라이버 해제를 누르세요.

출력 탭에 「준비되었습니다」가 표시되는 동안은 아직 어떤 앱도 카메라를 열지 않은 상태입니다 (오류가 아닙니다). 받는 쪽 앱에서 VRCast Camera를 선택하면 「전송 중」으로 바뀝니다.

Discord 등에서 카메라가 시작되지 않을 때 (Windows 11)

  1. 출력 탭에서 Windows 11 방식 (Media Foundation)으로 출력을 켭니다.
  2. 드라이버 등록으로 이 방식의 드라이버를 등록합니다 (방식마다 한 번, 관리자 확인이 표시됩니다).
  3. 사용할 앱에서 VRCast Camera (MF)를 선택합니다.

Windows의 일반 카메라로 취급되므로 기존 방식이 목록에 없거나 시작에 실패하는 앱에서도 사용할 수 있는 경우가 있습니다. VRCast가 실행 중이고 출력이 켜져 있는 동안에만 목록에 표시됩니다. 드라이버는 Program Files에 복사되므로 VRCast 폴더를 이동해도 다시 등록할 필요가 없습니다.

Spout2 (OBS로 가볍게·투명 그대로)

  1. OBS에 Spout2 플러그인을 설치합니다.
  2. 출력 탭의 Spout2에서 출력하기 (VRCast)를 켭니다.
  3. OBS에서 Spout2 Capture 소스를 추가하고 송신원으로 VRCast를 선택합니다.
  4. 배경을 투명하게 하려면 VRCast에서 배경을 투명하게를 켜고, OBS의 Spout2 Capture 소스 속성에서 Composite mode를 Default로 설정합니다 (그대로 두면 배경이 투명해지지 않습니다).

GPU에서 영상을 전달하므로 게임 캡처나 가상 카메라보다 가볍고, 배경 투명도 그대로 전달됩니다. 조작 패널은 표시되지 않습니다. 해상도는 VRCast 창 크기입니다.

외형·조명 (표시·그래픽 탭)

카메라와 해상도는 표시 탭, 배경·조명·윤곽선은 그래픽 탭에 있습니다.

항목 내용
카메라 화각 변경과 초기화. 오른쪽 드래그로 회전, 가운데 드래그로 이동, 휠로 확대·축소. 카메라 위치와 화각은 아바타마다 기억되며, 다시 시작한 후에도 유지됩니다. 카메라 고정을 켜면 마우스 드래그·휠로 움직이지 않습니다 (화각과 초기화는 사용 가능). 아바타 안으로 들어가지 않기(기본은 켜짐)가 켜져 있으면 가까이 가도 몸 앞에서 카메라가 멈추고, 그 이상은 화각을 좁혀 클로즈업합니다.
배경 배경색 (기본은 베이지)과 투명 전환. 투명 중에도 VRCast 창에서는 배경색이 보이지만, OBS 게임 캡처에서는 투명해집니다.
해상도 창 크기 (가로·세로 프리셋).
조명 환경광은 아바타 전체를 고르게 밝히고, 태양광은 한 방향에서 비춥니다. 어두울 때는 맑음 프리셋을 누르거나 환경광을 올리세요. 태양광 색은 낮을수록 따뜻한 색입니다. 방향 0이면 정면에서 비춥니다. 조명으로 밝아지지 않으면 아바타 밝기를 올립니다. 조명과 아바타 밝기는 아바타마다 기억됩니다.
윤곽선 굵기로 아바타 윤곽선 (lilToon / MToon / Poiyomi / UTS)을 굵게·가늘게 할 수 있습니다 (0~3, 1 = 머티리얼 그대로, 0 = 윤곽선 없음). 머티리얼 그대로 (1)로 되돌립니다. 아바타마다 기억됩니다.

몸·포즈 탭에서는 아바타의 방향·팔 내리는 정도를, 얼굴·표정 탭에서는 표정을 변경할 수 있습니다. 표정마다 단축키를 할당할 수 있습니다 (기본은 모두 미할당). 키 버튼을 누른 뒤 할당할 키를 누르고 (Ctrl+Alt+N 같은 동시 입력, 숫자 키패드 (NumLock 켜짐에서 숫자 키와 구별), 기호 키, 오른쪽 Ctrl 등의 단독 키 (눌렀다 떼기), 마우스 사이드 버튼도 가능), Esc로 취소합니다 (Tab은 사용할 수 없습니다). 옆의 초기화로 할당을 해제합니다 (아바타별로 저장). VRCast가 뒤에 있을 때도 사용(기본 켜짐)이면 OBS 등을 조작하는 중에도 전환할 수 있습니다. 다른 앱에서 입력하는 동안에도 반응하므로 Ctrl이나 Alt와의 조합을 권장합니다. 버튼·키로 고른 표정은 고정되어 자동 감지로 바뀌지 않습니다. 같은 표정을 다시 고르거나 자동 감지로 복귀를 누르면 돌아갑니다. 소품 전환 등도 포함한 클립에서 BlendShape만 꺼낸 표정은 기본적으로 목록에 나오지 않습니다. 다른 클립도 표시를 켜면 나옵니다 (해당 클립이 있는 아바타에서만 표시). 단축키·연동 탭에는 불러온 아바타의 표정별 명령이 나열되며 (복사로 복사), 포트 아래에 OSC 대상과 HTTP URL이 표시됩니다 (브라우저에서 상태 열기로 동작 확인. Stream Deck에서는 "웹사이트"의 "백그라운드에서 GET"에 URL 전체를 설정). 외부 조작 (OSC / HTTP)을 켜면 Stream Deck이나 OSC 앱에서 표정을 전환할 수 있습니다 (이 PC에서만. 예: http://127.0.0.1:39571/expression?name=Smile&toggle=1, OSC /vrcast/expression "Smile". 번호는 0 = 무표정, 1 이후 = 표정 순서).

몸·포즈 탭의 대기 모션(기본 켜짐, Humanoid만)은 웹캠을 쓰지 않을 때 아바타가 완전히 멈춰 보이지 않도록 호흡·몸 흔들림·머리 흔들림을 조금 더합니다. 호흡 · 몸 흔들림을 끄면 멈춥니다. 켜져 있을 때는 호흡·몸 흔들림·머리 흔들림의 강도 (0~2, 1이 표준)와 속도 (0.5~2배)를 조정할 수 있습니다. 얼굴 트래킹 중에는 머리 흔들림을 멈추고 본인의 움직임을 따릅니다. 같은 탭의 흔들림에서 흔들림 (PhysBone 근사)을 켜고 끌 수 있습니다.

의상·소품·파티클 켜고 끄기 (오브젝트 탭)

아바타에 파티클(Particle System)이 있으면 오브젝트 탭 아래에 파티클 항목이 나옵니다. 이펙트별 스위치나 모두 켜기 / 모두 끄기로 표시를 전환할 수 있습니다 (아바타별로 저장). 처음에는 VRChat의 초기 상태(FX 토글) 그대로이며, 켜면 숨겨진 상위 오브젝트도 표시합니다. 새 내보내기 도구로 다시 내보낸 아바타에서 사용할 수 있습니다. 꺼져 있는 파티클도 내보내므로 내보내기 전에 모두 켤 필요가 없습니다. VRChat에서 함께 켜고 끄는 것(FX 토글·이펙트 폴더)은 하나로 묶어 표시합니다. 이름 변경으로 표시 이름을 붙일 수 있고 (비워 두면 Unity의 이름으로 돌아감), 각 행 아래에 Unity의 경로가 나옵니다.

아바타의 내용이 Unity의 Hierarchy와 같은 순서로 나옵니다. 체크하면 표시, 해제하면 숨깁니다 (Unity Inspector의 체크와 같음). 전환은 아바타별로 저장됩니다. 내보내기 도구의 비활성 오브젝트도 내보내기(기본 켜짐)를 켜고 내보내면 씬에서 꺼 둔 의상·소품도 꺼진 상태로 들어가므로 여기서 켤 수 있습니다 (1.18.7 이후의 내보내기 도구).

VRChat 메뉴로 전환하는 것만을 켜면 VRChat Expression Menu(FX 토글)로 전환하는 의상·소품만 나열됩니다 (해당하는 것이 있는 아바타는 처음부터 켜짐). 끄면 ▶ / ▼로 펼치고 접을 수 있는 트리 표시가 됩니다. 본·빈 오브젝트 숨기기(기본 켜짐)로 메시가 없는 행을 생략하고, 검색으로 이름 일부로 찾을 수 있습니다. 변경 되돌리기로 불러왔을 때의 상태로 돌아갑니다. 상위가 꺼져 보이지 않는 행은 흐리게 표시됩니다.

립싱크·눈 깜빡임 (얼굴·표정 탭)

  • 마이크로 립싱크를 켜고 마이크를 선택한 뒤, 음량 미터를 보면서 마이크 감도와 노이즈 게이트 (이 음량 이하는 무음)를 조정합니다.
  • 모음으로 입 모양 바꾸기가 켜져 있으면 VRChat처럼 "아이우에오"로 입 모양이 바뀝니다. 판별이 어긋나면 목소리 높이 보정을 움직입니다 (목소리가 높은 사람은 오른쪽).
  • 자동 눈 깜빡임도 켜고 끌 수 있습니다 (흔들림은 몸·포즈 탭).
  • 표정 중에는 눈 깜빡이지 않기를 켜면 표정을 짓는 동안 자동 눈 깜빡임과 트래킹의 눈 깜빡임이 모두 멈춰 표정의 눈 모양이 흐트러지지 않습니다.
  • 눈 깜빡임 / 시선의 카메라 시선을 켜면 눈을 화면으로 향하게 합니다 (트래킹 시선 대신 사용하며 트래킹을 꺼도 동작). 패널 아래 버튼이나 단축키 (기본값: 숫자 키패드 5. 단축키·연동 탭에서 변경 가능)로도 전환할 수 있습니다.
  • 표정 중에는 마이크 립싱크 멈추기·표정 중에는 트래킹의 입 멈추기를 켜면 표정을 짓는 동안 각각의 입 움직임이 멈춥니다 (따로 고를 수 있고 둘 다 켤 수도 있습니다. 표정의 입과 립싱크가 겹치면 깨지는 아바타용).
  • 셰이프 키 설정 탭의 BlendShape 상한에서 BlendShape마다 움직이는 최대값(100 = 제한 없음)을 정할 수 있습니다. 눈을 깜빡일 때 눈이 사라지거나 입을 벌리면 얼굴이 깨질 때는 해당 BlendShape를 낮춰 주세요. 대상에서 얼굴 (눈 깜빡임·입·표정)(눈 깜빡임·립싱크·표정·퍼펙트 싱크로 움직이는 것) 또는 기타(체형·옷 등)를 고르고 검색으로 좁힐 수 있습니다. 설정은 아바타별로 저장됩니다. 트래킹 표정에는 상한을 적용하지 않기(기본 켜짐)가 켜져 있으면 트래킹 탭의 표정 반영으로 바뀐 표정은 상한 없이 움직입니다 (직접 고른 표정·눈 깜빡임·립싱크·퍼펙트 싱크에는 상한이 적용됩니다).

퍼펙트 싱크화 (퍼펙트 싱크화 탭)

ARKit 이름의 BlendShape가 없는 아바타도 얼굴에 표시를 찍으면 퍼펙트 싱크용 51종의 형상을 자동으로 만들 수 있습니다. 원래 있는 BlendShape('아'·눈 깜빡임·웃음 등)는 자동으로 할당해 사용합니다. 결과는 새 .vrcaster로 다른 이름으로 저장하며 원본 파일은 바꾸지 않습니다.

  • 메시의 정점을 읽기 때문에 2.0.0 이후의 내보내기 도구로 다시 내보낸 .vrcaster가 필요합니다 (VRM은 대상 외). 탭 목록 맨 아래의 보라색 퍼펙트 싱크화 탭에서 편집 시작으로 편집 화면으로 이동합니다. 편집 중에는 출력에도 얼굴 클로즈업이 나오고, 흔들림·대기 모션·트래킹·눈 깜빡임·립싱크는 멈춥니다 (닫으면 원래대로 돌아옵니다).
  • 1. 표시: 얼굴 메시와 세밀도(최소 (약 10점) / 표준 (약 20점) / 상세 (약 40점))를 고르고, 그림에서 빛나는 표시를 얼굴 위에서 왼쪽 클릭해 찍습니다. 드래그로 움직일 수 있습니다 (시점은 얼굴 정면에 고정되며 휠로 확대·가운데 드래그로 이동. 시점을 얼굴 정면에 고정을 끄면 오른쪽 드래그로 회전). 잘못 찍었을 때는 그림 아래의 실행 취소(Ctrl+Z)로 하나씩 되돌리고, 지우기(Delete 키)로 선택한 표시(찍지 않았다면 방금 찍은 표시)를 지울 수 있습니다. 왼쪽 표시를 오른쪽에도 반영 (좌우 대칭)이 켜져 있으면 오른쪽은 자동으로 놓입니다. '아바타의 왼쪽'은 정면에서 볼 때 오른쪽입니다(표시 이름에도 '화면 오른쪽·아바타의 왼쪽'처럼 나옵니다). 최소 표시(눈·눈썹·입꼬리·입술·턱)가 갖춰지면 생성해서 확인을 누릅니다.
  • 2. 형상: 형상마다 자동 생성 / 기존 BlendShape / 없음과 강도를 고르고 반영으로 확인합니다. 눈의 움직임(eyeLook)은 눈 본이 시선으로 움직이므로 기본값은 없음입니다(눈 본이 없는 아바타는 자동 생성). 만들어도 움직일 부분이 없었던 형상에는 움직일 부분 없음이 표시되므로 기존 BlendShape 또는 없음을 고르세요.
  • 이 아바타에 없는 부위에서 눈썹 / 코 / 입 안을 고르면 그 부위의 표시는 찍지 않아도 되고, 그 부위의 형상은 기본값이 없음이 됩니다(입 안이나 혀가 만들어지지 않은 아바타는 '아' 등 기존 BlendShape로 입을 움직입니다). 별도의 치아·혀 메시가 없는 아바타에서는 치아·혀 메시도 턱과 함께 움직이기를 고를 수 없습니다. 없는 부위가 있는 아바타에서는 기대한 대로 움직이지 않을 수 있습니다.
  • 자동으로 찍기의 두 버튼으로 아직 찍지 않은 표시를 자동으로 놓을 수 있습니다(찍은 표시는 바뀌지 않으며 실행 취소로 취소할 수 있습니다). BlendShape에서는 아바타의 눈 깜빡임·'아'·'우'·눈썹 BlendShape로 움직이는 부분에서 눈·입·눈썹·코끝을 구합니다. 이미지 인식은 얼굴을 정면으로 한 뒤 누르면 지금 화면의 얼굴을 MediaPipe로 인식해 놓습니다(애니메이션풍 얼굴은 찾지 못할 수 있습니다). 둘 다 위치는 대략적이므로 어긋난 표시는 드래그로 고치세요.
  • 저장하기 전에 2. 형상의 실제 트래킹으로 확인 (저장하기 전에)를 켜면, 확인 중인 형상 그대로 자신의 얼굴 움직임으로 확인할 수 있습니다(트래킹 탭에서 트래킹과 퍼펙트 싱크를 켜 두세요). 형상을 바꾸면 반영으로 갱신됩니다.
  • 다른 이름으로 저장...(기본값: '원래 이름_PerfectSync.vrcaster')으로 저장하고 저장한 아바타 불러오기로 열면 트래킹 탭의 퍼펙트 싱크로 얼굴이 움직입니다. 퍼펙트 싱크 버전을 다시 편집하면 저장한 표시에서 이어서 고칠 수 있습니다. 이 파일은 2.0.0 이전의 VRCast에서는 열 수 없습니다. 닫기를 누르면 확인이 나오고, 저장하지 않고 닫기로 저장하지 않은 변경을 버리고 원래 화면으로 돌아갑니다.

웹캠 트래킹 (트래킹 탭)

  • 트래킹 사용을 켜면 포함된 트래커가 자동으로 시작되어 머리 방향·눈 깜빡임·입·시선 (MediaPipe에서는 팔·손도)이 움직입니다.
  • MediaPipe에서 팔·손이 켜져 있으면 상체 비틀기·기울기 (어깨)(기본은 켜짐)로 양 어깨 방향에 맞춰 상체를 비틀거나 좌우로 기울입니다. 어깨가 보이지 않는 동안은 머리 위치로 기울입니다. 비틀지 않게 하려면 상체 비틀기 고정을 켜면 좌우 기울기만 움직입니다. 원시 데이터 표시에서는 상체 방향을 초록 상자와 각도로 확인할 수 있습니다 (골격은 아바타 크기에 맞춰 그리므로 카메라를 움직일 필요가 없습니다).
  • 입력 소스는 세로로 나열된 스위치 중 하나를 켜서 고릅니다. 각 줄 오른쪽 (폭이 부족하면 스위치 아래)에 권장 (MediaPipe)과 PC 부하 기준 (낮음·보통·높음)이 표시됩니다. MediaPipe는 팔·손을 끄면 가벼워지고, iPhone 등에서 받는 입력 소스는 스마트폰에서 추정하므로 PC 부하가 낮습니다.
  • 눈 깜빡임 트래킹(기본은 켜짐)을 끄면 눈의 개폐를 따라가지 않고 얼굴·표정 탭의 자동 눈 깜빡임을 사용합니다 (퍼펙트 싱크에서도 눈 깜빡임만은 움직이지 않습니다).
  • 눈을 뜨고 있는데 아바타가 반쯤 감은 눈이 되면 눈 뜨기 보정(기본값 0)을 올립니다. 그 값까지 감긴 정도는 뜬 눈으로 취급하고, 깜빡임에서는 완전히 감깁니다 (퍼펙트 싱크와 표정 반영의 실눈 판정에도 적용되며, 눈 깜빡임 트래킹이 켜져 있을 때만 표시됩니다).
  • 눈을 깜빡이거나 옆을 볼 때 의도치 않게 윙크가 되거나 양쪽 눈의 뜨인 정도가 달라지면 양쪽 눈 맞추기(기본은 끄기)를 선택합니다. 항상은 양쪽 눈을 항상 맞춥니다 (깜빡임은 되지만 윙크는 할 수 없습니다). 옆을 볼 때만은 얼굴이 옆을 향할 때만 맞춥니다 (퍼펙트 싱크에도 적용).
  • 감은 눈·윙크가 머리 기울기나 팔과 반대쪽이 될 때는 움직임 항목의 얼굴 좌우 바꾸기(기본은 꺼짐)를 켭니다. 얼굴 (눈 깜빡임·퍼펙트 싱크·시선)만 바뀌고, 머리 방향과 팔은 미러 설정 그대로입니다.
  • 얼굴은 맞는데 팔·상체만 좌우가 반대일 때 (iPhone 얼굴 + 웹캠 팔 병용 등)는 움직임 항목의 몸 좌우 바꾸기(기본은 꺼짐)를 켭니다. 몸 (팔·손·어깨 비틀림·기울기)만 바뀌고, 머리 방향과 얼굴은 미러 그대로입니다.
  • MediaPipe·iPhone·외부 앱 (VMC)·iFacialMocap에서 표정 반영을 켜면 (기본은 켜짐) 웃음·놀람·화남·슬픔·윙크·실눈·뾰로통을 감지해 아바타의 표정으로 바꿉니다 (할당할 표정이 없는 것은 감지하지 않습니다). 표정별 임계값으로 반응 정도를 (낮을수록 쉽게 반응. 원시 데이터 표시 중에 나오는 표정 값이 기준), 표정별 선택으로 사용할 표정을 바꿀 수 있습니다 (자동은 표정 이름으로 추정).
  • MediaPipe·iPhone·외부 앱 (VMC)·iFacialMocap에서는 퍼펙트 싱크(기본은 켜짐)도 지원합니다. ARKit 이름의 BlendShape(eyeBlinkLeft·jawOpen·mouthSmileLeft 등)가 있는 아바타라면 눈썹·볼·입 모양까지 얼굴 움직임대로 움직입니다. 활성화 조건에서 20종 이상(기본) 또는 1종이라도를 선택할 수 있으며, 지원 여부는 그 아래에 개수로 표시됩니다. 퍼펙트 싱크 중에는 표정 반영의 자동 전환이 멈춥니다(20종 미만으로 움직일 때는 함께 사용합니다).
  • 입·볼 움직임 강조(기본은 켜짐)는 퍼펙트 싱크로 얼굴을 움직이는 동안에만, 카메라에서 약하게 잡히기 쉬운 입 내밀기·입 좌우·볼 부풀리기·입술 움직임을 배율(1~5)로 강하게 합니다(입 좌우 배율은 기본 1배). 움직임이 작으면 값을 올리고, 너무 쉽게 움직이면 낮추세요. MediaPipe에서는 입 좌우와 볼 부풀리기를 얼굴 형태로 추정합니다. 시작 후 몇 초 동안 무표정을 유지하면 평소 얼굴을 기억해 정확하게 측정합니다. 볼 부풀리기 감지의 시작 (%)은 무표정일 때 값보다 조금 위로, 최대 (%)는 볼을 부풀렸을 때 값 정도로 설정합니다(현재 값은 설정 아래에 표시됩니다). 퍼펙트 싱크화의 실제 트래킹으로 확인 중에는 같은 설정이 왼쪽의 입·볼 조정 패널에도 나옵니다. 바꾼 값은 트래킹 탭에 바로 반영되고, 설정 저장으로 파일에 남깁니다.
  • 카메라는 < >로 선택합니다. 움직이지 않으면 트래커 다시 시작.
  • 입력 소스를 iPhone·외부 앱 (VMC, 얼굴 + 전신)으로 하면 카메라 대신 스마트폰 앱 (iPhone의 Waidayo 등)이나 PC 앱 (VirtualMotionCapture 등)에서 VMC 프로토콜로 움직임을 받습니다. PC와 스마트폰을 같은 Wi-Fi에 연결하고, 트래킹 탭에 나오는 이 PC의 IP 주소와 UDP 포트(기본 39539)를 앱의 전송 대상에 입력하세요 (이 PC에서 실행하는 앱이면 127.0.0.1). 처음에는 Windows 방화벽 확인 창이 나오므로 개인 네트워크에서 허용하세요. ARKit 값을 보내는 앱이라면 퍼펙트 싱크와 표정 반영도 사용할 수 있습니다. 전신을 보내는 앱에서는 전신 (전송 측 아바타의 움직임)(기본은 켜짐)으로 허리·다리·팔·손가락과 몸 전체 위치도 전송 측 아바타처럼 움직입니다. 똑바로 서서 카메라 쪽을 보고 초기화의 얼굴 방향을 누르면 정면이 맞춰집니다. 발을 바닥에 맞추기(기본은 켜짐)는 전송 측과 아바타의 다리 길이 차이로 발이 뜨거나 파묻히지 않도록 무릎을 굽혀 발 위치를 맞춥니다.
  • 입력 소스를 iFacialMocap (iPhone, 얼굴만)으로 하면 iPhone의 iFacialMocap에서 얼굴 움직임을 받습니다. PC와 iPhone을 같은 Wi-Fi에 연결하고, iFacialMocap 화면 위쪽에 나오는 IP 주소를 트래킹 탭의 iPhone IP 주소에 입력하세요 (UDP 포트 49983을 사용합니다). 처음에는 Windows 방화벽 확인 창이 나오므로 개인 네트워크에서 허용하세요. 퍼펙트 싱크와 표정 반영도 사용할 수 있습니다 (팔·손은 움직이지 않습니다).
  • 정면이 어긋나면 카메라를 보고 패널 아래쪽 초기화의 얼굴 방향 (얼굴·상체·시선)을 누릅니다. 시선만이라면 시선.
  • 정면은 트래킹 시작 시 (입력 소스·카메라 변경 후에도) 머리가 0.5초 정도 멈췄을 때의 방향으로 자동으로 정해집니다. 손으로 얼굴을 가리는 등으로 놓쳐도 정면은 다시 잡지 않습니다.
  • 몸의 움직임에서 머리 움직임에 맞춰 상체를 기울일지 몸 전체를 움직일지 선택할 수 있습니다.
  • 전신을 비출 때 전신 모드 (발 고정)를 켜면 발을 바닥에 둔 채 허리도 상체의 기울기·이동을 따라가고 무릎을 굽혀 흡수합니다.

다른 앱 (Discord·Zoom·VSeeFace 등)이 웹캠을 사용 중이면 시작할 수 없습니다.

성능 (성능 탭)

  • 저부하 모드 (기본은 켜짐): 화면을 30fps (끄면 60fps)로 제한하고 OpenSeeFace는 가벼운 모델을 써서 게임이나 OBS와 함께 쓸 때의 부하를 줄입니다. MediaPipe의 부하는 트래킹 탭의 트래커 동작에서 고릅니다.
  • 동작 상태 표시 (기본은 켜짐): 패널 맨 아래에 화면 FPS·VRCast의 CPU 사용률·GPU 처리 시간·내장 트래커의 CPU 사용률·트래킹 수신 속도를 영어로 표시합니다 (1초마다 갱신). 무거울 때 원인을 짐작하는 데 쓸 수 있습니다.
  • 프로세스 우선순위 (기본은 「보통」): VRCast 본체와 내장 트래커의 우선순위를 함께 바꿉니다 (바로 적용). 게임 중에 트래킹이 끊기면 올려 주세요. 「높음」으로 하면 다른 앱이 느려질 수 있습니다.
  • CPU 설정 › AMD (X3D) › 3D V-Cache가 없는 쪽 코어에서 실행 (기본은 켜짐. 7950X3D / 9950X3D 등 3D V-Cache가 한쪽 CCD에만 있는 CPU에서만 효과가 있으며, 이 PC가 대상인지는 설정 아래에 표시됩니다): 게임 중에는 Windows가 앱을 게임과 같은 코어로 모으므로, VRCast 본체와 내장 트래커를 반대쪽 코어에서 실행해 게임과 코어를 다투지 않게 합니다 (바로 적용). VRCast 자체가 게임으로 판정되면 Game Bar(Win + G) 설정에서 「이것을 게임으로 기억」을 꺼 주세요.
  • CPU 설정 › Intel (P 코어 / E 코어) › 사용할 코어 (기본은 「자동」. P 코어와 E 코어가 있는 Intel CPU(12세대 이후, Core Ultra)에서만 효과가 있습니다): VRCast 본체와 내장 트래커를 실행할 코어를 고릅니다 (바로 적용). E 코어만은 P 코어를 게임에 양보하지만 트래킹과 렌더링이 느려질 수 있습니다. P 코어만은 빠르지만 게임과 코어를 다툽니다. 잘 모르겠으면 「자동」으로 두세요.
  • 렌더링에 사용할 GPU (기본은 「자동」): 자동 / 절전 / 고성능을 고르거나 목록에서 GPU를 직접 고를 수 있습니다. VRCast를 다시 시작하면 적용됩니다 (VRCast 지금 다시 시작 버튼. PC 재시작은 필요 없습니다). OBS 캡처나 가상 카메라를 쓸 때는 OBS와 같은 GPU가 가장 가볍습니다. 내장 트래커는 CPU로 동작하므로 이 설정과 관계없습니다.
  • NVIDIA 인스턴트 리플레이 (NVIDIA GPU가 있는 PC에서만 표시): NVIDIA 인스턴트 리플레이가 감지하지 않게 하기를 누르면 VRCast가 인스턴트 리플레이(ShadowPlay)에 게임으로 감지되지 않도록 드라이버 설정에 VRCast용 프로필을 씁니다. VRCast를 다시 시작하면 적용됩니다. NVIDIA 인스턴트 리플레이 감지 되돌리기로 되돌릴 수 있습니다. 비공식 설정이라 드라이버에 따라 효과가 없을 수 있습니다. 변경하지 못했다고 표시되면 VRCast를 관리자 권한으로 실행해 보세요.

문제 해결

아바타가 어둡다

그래픽 탭의 맑음 프리셋을 누르거나 환경광을 올리세요. 방향을 0 근처로 하면 정면에서 빛이 비춥니다. lilToon 등은 밝기가 텍스처 색까지로 제한되므로, 태양광을 올려도 일정 이상은 밝아지지 않습니다. 그럴 때는 아바타 밝기를 올리세요 (0.1~10, 1 = 머티리얼 그대로).

OBS에서 배경이 투명해지지 않는다

VRCast의 배경을 투명하게 하고, OBS는 게임 캡처 (윈도우 캡처가 아님)에서 투명도 허용에 체크되어 있는지 확인하세요.

OBS에 아무것도 표시되지 않는다

게임 캡처의 창으로 [VRCast.exe]: VRCast를 다시 선택하세요. VRCast를 최소화하면 표시되지 않을 수 있습니다.

드래그 앤 드롭이 안 된다

VRCast를 관리자 권한으로 실행하면 Windows 제한으로 드롭할 수 없습니다. 일반적으로 실행하거나 파일 선택...을 사용하세요.

게임이나 OBS와 함께 쓰면 트래킹이 끊긴다

성능 탭의 저부하 모드가 켜져 있는지 확인하세요 (기본은 켜짐). MediaPipe라면 트래킹 탭의 트래커 동작을 부드럽게로 하면 부하가 줄고, 절약으로 하면 다시 절반 정도가 됩니다 (기본값인 매끄럽게 (고부하)는 손가락을 매끄럽게 움직이기 위해 무거운 편입니다). 그래도 무거우면 쓰지 않는 팔·손 트래킹을 끄면 부하가 줄어듭니다. 프로세스 우선순위를 「보통 이상」으로 하는 것도 효과가 있습니다.

립싱크가 안 된다

얼굴·표정 탭에서 올바른 마이크가 선택되어 있는지, 음량 미터가 움직이는지 확인하고, 움직이지 않으면 마이크 감도를 올리거나 노이즈 게이트를 낮추세요.

표정이 바뀌지 않는다

표정 반영은 MediaPipe·iPhone·외부 앱 (VMC)·iFacialMocap만 지원합니다. 트래킹 탭에서 입력 소스가 그중 하나인지, 표정 반영이 켜져 있는지 확인하세요. 반응이 약하면 표정 임계값을 낮추고, 다른 표정이 나오면 표정별 선택에서 사용할 표정을 지정하세요.

카메라가 인식되지 않는다·트래킹이 안 된다

먼저 트래킹 탭의 카메라에서 사용 중인 웹캠이 선택되어 있는지 확인하세요. VRCast Camera(VRCast의 가상 카메라)·OBS Virtual Camera 등의 가상 카메라나 얼굴 인증용 적외선(IR) 카메라를 선택하면 영상은 들어와도 얼굴이 인식되지 않습니다.

정보 탭 맨 아래의 디버그 로그에서 카메라 목록·트래커 상태와 시작 후의 로그를 확인할 수 있습니다. WARN / ERROR만 표시하거나, 카테고리를 Tracker / TrackerOutput / Tracking(카메라 관련)으로 좁힐 수 있습니다. 문제를 보고할 때는 표시 중 복사를 눌러 로그와 환경을 그대로 붙여 넣어 주세요.

원인을 알 수 없을 때는 상세 로그를 켜고 증상이 나타날 때까지 기다린 뒤 복사해 주세요. 수신 통계(초당 데이터 수, 얼굴·팔·손이 보였던 비율)와 MediaPipe 추정 시간 등이 DEBUG로 기록됩니다. 설정은 저장되므로 조사가 끝나면 다시 꺼 주세요.
