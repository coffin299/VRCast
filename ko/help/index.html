빠른 시작

VRCast는 VRChat용 아바타를 단독으로 표시하고 OBS 같은 방송 소프트웨어에 보내는 앱입니다. VRCast를 실행하면 왼쪽 패널에 시작하기 탭이 열리고, 같은 단계를 화면에서 안내합니다.

  1. Unity에서 아바타를 .vrcaster 파일로 내보내기
  2. .vrcaster 파일을 VRCast 창에 드래그 앤 드롭
  3. VRM(.vrm, VRoid 등)은 내보낼 필요 없이 그대로 드래그 앤 드롭 (VRM에 대해)
  4. 시작하기 탭의 투명하게 하기를 누르기
  5. OBS에서 게임 캡처를 추가하고 투명도 허용에 체크
  6. Tab 키로 조작 패널 숨기기

1. 아바타 내보내기 (Unity)

아바타가 들어 있는 Unity 프로젝트 (VCC로 만든 프로젝트도 가능, Unity 2022.3.22f1)에서 작업합니다.

  1. 배포 zip의 VRCast-Converter 폴더(본체 VRCast 폴더와 별도)에 있는 VRCast-Converter-버전.unitypackage를 더블 클릭 (또는 Unity에 드래그 앤 드롭)하고 Import를 누릅니다 (Assets/VRCast/Converter에 들어갑니다).
  2. 메뉴 VRCast > Avatar Exporter를 엽니다.
  3. 씬의 아바타 (가장 위의 부모 오브젝트)를 지정하고 내보내기...를 눌러 저장 위치를 선택합니다. 화면은 OS 언어로 표시됩니다 (위쪽의 언어에서 전환 가능).

원본 아바타는 변경되지 않습니다. 표정·립싱크·눈 깜빡임·흔들림·Constraint 설정도 함께 내보내집니다.

씬에서 비활성(체크 해제)인 오브젝트는 자식을 포함해 내보내지지 않습니다. 표시하고 싶은 의상·소품은 활성화한 뒤 내보내세요.

블렌드셰이프는 Unity 씬에서 설정한 값 그대로 내보내집니다 (씬의 블렌드셰이프 값을 우선, 기본 ON). 의상 전환에 맞춰 축소용 블렌드셰이프를 FX로 움직이는 경우 등에는 OFF로 하면 VRChat에 들어갔을 때의 초기 상태 값으로 내보냅니다.

FX 레이어에 있는 표정 클립은 자동으로 내보내집니다. FX에 없는 표정(예전 아바타에 포함된 표정 애니메이션 등)은 내보내기 화면의 추가 표정에 애니메이션 클립이나 폴더를 드래그하면 표정으로 내보낼 수 있습니다 (블렌드셰이프만 움직이는 클립이 대상, 아바타별로 저장).

씬에 FaceEmo 설정이 있으면 그 아바타의 표정을 FaceEmo의 모드 이름으로 자동으로 내보냅니다 (FaceEmo의 「아바타에 적용」을 하지 않아도 됩니다. 소품 표시 등은 제외하고 블렌드셰이프 부분만 사용합니다).

[베타] Modular Avatar 등으로 개조한 아바타는 그대로 지정하면 개조 후의 모습 (의상 통합·추가한 표정과 토글)으로 내보내집니다. MA의 Merge Armature / Bone Proxy로 붙인 의상·소품은 통합되지 않은 경우에도 아바타의 본에 다시 붙여 몸을 따라가게 합니다. MA의 Blendshape Sync로 입 등에 따라가게 한 체인·소품도 립싱크·눈 깜빡임·트래킹을 따라갑니다. 임시 지원이므로 올바르게 내보내지지 않을 수 있습니다.

Package Manager로 설치하려면 Window > Package Manager의 + > Add package from git URL...에 https://github.com/coffin299/VRCast.git?path=/Packages/com.vrcast.converter 를 입력합니다 (Git 필요). unitypackage와 둘 다 설치하면 오류가 나므로 한쪽만 사용하세요.

2. VRCast에서 불러오기

  • .vrcaster 또는 .vrm 파일을 VRCast 창에 드래그 앤 드롭하면 불러옵니다.
  • 또는 시작하기 탭의 파일 선택..., 아바타 탭의 찾아보기...로 선택할 수 있습니다.
  • 마지막으로 불러온 아바타는 다음 실행 시 자동으로 불러옵니다.
  • 아바타 탭의 최근 사용한 아바타에 최근 사용한 아바타가 최대 10개 표시되며, 클릭하여 전환할 수 있습니다 (×를 누른 뒤 제거로 목록에서 제거). 카메라·조명·아바타 밝기·대기 포즈·몸 방향은 아바타마다 기억되어 전환하면 복원됩니다.

.vrcaster와 .vrm 이외의 파일 (이미지나 unitypackage 등)은 불러올 수 없습니다. .vrcaster에서 오류가 표시되면 다시 내보내세요.

VRM 불러오기

  • VRM 0.x / 1.0의 .vrm(VRoid Studio 등으로 만든 것)은 Unity에서 내보내지 않고 그대로 불러올 수 있습니다.
  • VRM의 표정(기쁨·분노·슬픔·편안·놀람·사용자 표정), 눈 깜빡임·윙크, 아이우에오 입 모양, 흔들림(SpringBone)을 VRCast의 표정·자동 눈 깜빡임·립싱크·흔들림으로 사용합니다.
  • 아바타 탭에 VRM 버전(0.x / 1.0)과 제작자가 표시됩니다.

머티리얼 색을 바꾸는 표정, VRM의 컨스트레인트, 눈 본이 없는 모델의 시선(BlendShape 방식)은 반영되지 않습니다. VRM에 적힌 이용 조건을 지켜 사용하세요.

3. OBS에 표시하기

  1. VRCast의 시작하기 탭 (또는 표시 탭)에서 배경을 투명하게 합니다. VRCast 창에서는 배경색이 그대로 보이지만, OBS에서는 배경이 투명해집니다.
  2. OBS의 소스 아래 +를 눌러 게임 캡처를 추가합니다.
  3. 모드를 특정 창 캡처, 창을 [VRCast.exe]: VRCast로 설정합니다.
  4. 투명도 허용에 체크합니다.
  5. VRCast에서 Tab 키를 눌러 조작 패널을 숨깁니다 (패널도 OBS에 표시되기 때문). 숨긴 동안에는 투명이 꺼져 있어도 OBS에서 배경이 투명해집니다.

윈도우 캡처는 투명을 지원하지 않습니다. 투명하게 하려면 반드시 게임 캡처를 사용하세요.

가상 카메라 (Discord / Zoom 등)

  1. 출력 탭에서 가상 카메라 출력을 켭니다.
  2. 처음 한 번만 드라이버 등록을 누릅니다 (관리자 확인이 표시됩니다).
  3. 사용할 앱의 카메라 선택에서 VRCast Camera를 선택합니다 (없으면 그 앱을 다시 시작).

조작 패널은 가상 카메라에 표시되지 않습니다. Discord 등은 투명을 표시할 수 없으므로 배경은 배경색으로 표시됩니다. VRCast 폴더를 이동·삭제하기 전에 드라이버 해제를 누르세요.

출력 탭에 「준비되었습니다」가 표시되는 동안은 아직 어떤 앱도 카메라를 열지 않은 상태입니다 (오류가 아닙니다). 받는 쪽 앱에서 VRCast Camera를 선택하면 「전송 중」으로 바뀝니다.

Discord 등에서 카메라가 시작되지 않을 때 (Windows 11)

  1. 출력 탭에서 Windows 11 방식 (Media Foundation)으로 출력을 켭니다.
  2. 드라이버 등록으로 이 방식의 드라이버를 등록합니다 (방식마다 한 번, 관리자 확인이 표시됩니다).
  3. 사용할 앱에서 VRCast Camera (MF)를 선택합니다.

Windows의 일반 카메라로 취급되므로 기존 방식이 목록에 없거나 시작에 실패하는 앱에서도 사용할 수 있는 경우가 있습니다. VRCast가 실행 중이고 출력이 켜져 있는 동안에만 목록에 표시됩니다. 드라이버는 Program Files에 복사되므로 VRCast 폴더를 이동해도 다시 등록할 필요가 없습니다.

Spout2 (OBS로 가볍게·투명 그대로)

  1. OBS에 Spout2 플러그인을 설치합니다.
  2. 출력 탭의 Spout2에서 출력하기 (VRCast)를 켭니다.
  3. OBS에서 Spout2 Capture 소스를 추가하고 송신원으로 VRCast를 선택합니다.
  4. 배경을 투명하게 하려면 VRCast에서 배경을 투명하게를 켜고, OBS의 Spout2 Capture 소스 속성에서 Composite mode를 Default로 설정합니다 (그대로 두면 배경이 투명해지지 않습니다).

GPU에서 영상을 전달하므로 게임 캡처나 가상 카메라보다 가볍고, 배경 투명도 그대로 전달됩니다. 조작 패널은 표시되지 않습니다. 해상도는 VRCast 창 크기입니다.

외형·조명 (표시 탭)

항목 내용
카메라 화각 변경과 초기화. 오른쪽 드래그로 회전, 가운데 드래그로 이동, 휠로 확대·축소. 카메라 위치와 화각은 아바타마다 기억되며, 다시 시작한 후에도 유지됩니다. 카메라 고정을 켜면 마우스 드래그·휠로 움직이지 않습니다 (화각과 초기화는 사용 가능).
배경 배경색 (기본은 베이지)과 투명 전환. 투명 중에도 VRCast 창에서는 배경색이 보이지만, OBS 게임 캡처에서는 투명해집니다.
해상도 창 크기 (가로·세로 프리셋).
조명 환경광은 아바타 전체를 고르게 밝히고, 태양광은 한 방향에서 비춥니다. 어두울 때는 맑음 프리셋을 누르거나 환경광을 올리세요. 태양광 색은 낮을수록 따뜻한 색입니다. 방향 0이면 정면에서 비춥니다. 조명으로 밝아지지 않으면 아바타 밝기를 올립니다. 조명과 아바타 밝기는 아바타마다 기억됩니다.

포즈·표정 탭에서는 아바타의 방향·팔 내리는 정도·표정을 변경할 수 있습니다. 표정마다 단축키를 할당할 수 있습니다 (기본은 모두 미할당). 키 버튼을 누른 뒤 할당할 키를 누르고 (Ctrl+Alt+N 같은 동시 입력, 숫자 키패드 (NumLock 켜짐에서 숫자 키와 구별), 기호 키, 오른쪽 Ctrl 등의 단독 키 (눌렀다 떼기), 마우스 사이드 버튼도 가능), Esc로 취소합니다 (Tab은 사용할 수 없습니다). 옆의 초기화로 할당을 해제합니다 (아바타별로 저장). VRCast가 뒤에 있을 때도 사용(기본 켜짐)이면 OBS 등을 조작하는 중에도 전환할 수 있습니다. 다른 앱에서 입력하는 동안에도 반응하므로 Ctrl이나 Alt와의 조합을 권장합니다. 버튼·키로 고른 표정은 고정되어 자동 감지로 바뀌지 않습니다. 같은 표정을 다시 고르거나 자동 감지로 복귀를 누르면 돌아갑니다. OSC / HTTP 탭 (출력과 설정 사이)에는 불러온 아바타의 표정별 명령이 나열되며 (복사로 복사), 포트 아래에 OSC 대상과 HTTP URL이 표시됩니다 (브라우저에서 상태 열기로 동작 확인. Stream Deck에서는 "웹사이트"의 "백그라운드에서 GET"에 URL 전체를 설정). 외부 조작 (OSC / HTTP)을 켜면 Stream Deck이나 OSC 앱에서 표정을 전환할 수 있습니다 (이 PC에서만. 예: http://127.0.0.1:39571/expression?name=Smile&toggle=1, OSC /vrcast/expression "Smile". 번호는 0 = 무표정, 1 이후 = 표정 순서).

대기 모션(기본 켜짐, Humanoid만)은 웹캠을 쓰지 않을 때 아바타가 완전히 멈춰 보이지 않도록 호흡·몸 흔들림·머리 흔들림을 조금 더합니다. 호흡 · 몸 흔들림을 끄면 멈춥니다. 켜져 있을 때는 호흡·몸 흔들림·머리 흔들림의 강도 (0~2, 1이 표준)와 속도 (0.5~2배)를 조정할 수 있습니다. 얼굴 트래킹 중에는 머리 흔들림을 멈추고 본인의 움직임을 따릅니다.

립싱크·눈 깜빡임 (얼굴 탭)

  • 마이크로 립싱크를 켜고 마이크를 선택한 뒤, 음량 미터를 보면서 마이크 감도와 노이즈 게이트 (이 음량 이하는 무음)를 조정합니다.
  • 모음으로 입 모양 바꾸기가 켜져 있으면 VRChat처럼 "아이우에오"로 입 모양이 바뀝니다. 판별이 어긋나면 목소리 높이 보정을 움직입니다 (목소리가 높은 사람은 오른쪽).
  • 흔들림 (PhysBone 근사)과 자동 눈 깜빡임도 켜고 끌 수 있습니다.
  • 표정 중에는 눈 깜빡이지 않기를 켜면 표정을 짓는 동안 자동 눈 깜빡임과 트래킹의 눈 깜빡임이 모두 멈춰 표정의 눈 모양이 흐트러지지 않습니다.
  • 흔들림 / 눈 깜빡임 / 시선의 카메라 시선을 켜면 눈을 화면으로 향하게 합니다 (트래킹 시선 대신 사용하며 트래킹을 꺼도 동작). 패널 아래 버튼이나 단축키 (기본값: 숫자 키패드 5. 설정 탭에서 변경 가능)로도 전환할 수 있습니다.
  • 표정 중에는 마이크 립싱크 멈추기·표정 중에는 트래킹의 입 멈추기를 켜면 표정을 짓는 동안 각각의 입 움직임이 멈춥니다 (따로 고를 수 있고 둘 다 켤 수도 있습니다. 표정의 입과 립싱크가 겹치면 깨지는 아바타용).
  • 셰이프 키 설정 탭의 BlendShape 상한에서 BlendShape마다 움직이는 최대값(100 = 제한 없음)을 정할 수 있습니다. 눈을 깜빡일 때 눈이 사라지거나 입을 벌리면 얼굴이 깨질 때는 해당 BlendShape를 낮춰 주세요. 대상에서 얼굴 (눈 깜빡임·입·표정)(눈 깜빡임·립싱크·표정·퍼펙트 싱크로 움직이는 것) 또는 기타(체형·옷 등)를 고르고 검색으로 좁힐 수 있습니다. 설정은 아바타별로 저장됩니다. 트래킹 표정에는 상한을 적용하지 않기(기본 켜짐)가 켜져 있으면 트래킹 탭의 표정 반영으로 바뀐 표정은 상한 없이 움직입니다 (직접 고른 표정·눈 깜빡임·립싱크·퍼펙트 싱크에는 상한이 적용됩니다).

웹캠 트래킹 (트래킹 탭)

  • 트래킹 사용을 켜면 포함된 트래커가 자동으로 시작되어 머리 방향·눈 깜빡임·입·시선 (MediaPipe에서는 팔·손도)이 움직입니다.
  • MediaPipe에서 팔·손이 켜져 있으면 상체 비틀기·기울기 (어깨)(기본은 켜짐)로 양 어깨 방향에 맞춰 상체를 비틀거나 좌우로 기울입니다. 어깨가 보이지 않는 동안은 머리 위치로 기울입니다. 비틀지 않게 하려면 상체 비틀기 고정을 켜면 좌우 기울기만 움직입니다. 원시 데이터 표시에서는 상체 방향을 초록 상자와 각도로 확인할 수 있습니다 (골격은 아바타 크기에 맞춰 그리므로 카메라를 움직일 필요가 없습니다).
  • 입력 소스는 세로로 나열된 스위치 중 하나를 켜서 고릅니다. 각 줄 오른쪽 (폭이 부족하면 스위치 아래)에 권장 (MediaPipe)과 PC 부하 기준 (낮음·보통·높음)이 표시됩니다. MediaPipe는 팔·손을 끄면 가벼워지고, iPhone 등에서 받는 입력 소스는 스마트폰에서 추정하므로 PC 부하가 낮습니다.
  • 눈 깜빡임 트래킹(기본은 켜짐)을 끄면 눈의 개폐를 따라가지 않고 얼굴 탭의 자동 눈 깜빡임을 사용합니다 (퍼펙트 싱크에서도 눈 깜빡임만은 움직이지 않습니다).
  • 감은 눈·윙크가 머리 기울기나 팔과 반대쪽이 될 때는 움직임 항목의 얼굴 좌우 바꾸기(기본은 꺼짐)를 켭니다. 얼굴 (눈 깜빡임·퍼펙트 싱크·시선)만 바뀌고, 머리 방향과 팔은 미러 설정 그대로입니다.
  • MediaPipe·iPhone·외부 앱 (VMC)·iFacialMocap에서 표정 반영을 켜면 (기본은 켜짐) 웃음·놀람·화남·슬픔·윙크·실눈·뾰로통을 감지해 아바타의 표정으로 바꿉니다 (할당할 표정이 없는 것은 감지하지 않습니다). 표정별 임계값으로 반응 정도를 (낮을수록 쉽게 반응. 원시 데이터 표시 중에 나오는 표정 값이 기준), 표정별 선택으로 사용할 표정을 바꿀 수 있습니다 (자동은 표정 이름으로 추정).
  • MediaPipe·iPhone·외부 앱 (VMC)·iFacialMocap에서는 퍼펙트 싱크(기본은 켜짐)도 지원합니다. ARKit 이름의 BlendShape(eyeBlinkLeft·jawOpen·mouthSmileLeft 등)가 있는 아바타라면 눈썹·볼·입 모양까지 얼굴 움직임대로 움직입니다. 활성화 조건에서 20종 이상(기본) 또는 1종이라도를 선택할 수 있으며, 지원 여부는 그 아래에 개수로 표시됩니다. 퍼펙트 싱크 중에는 표정 반영의 자동 전환이 멈춥니다(20종 미만으로 움직일 때는 함께 사용합니다).
  • 카메라는 < >로 선택합니다. 움직이지 않으면 트래커 다시 시작.
  • 입력 소스를 iPhone·외부 앱 (VMC, 얼굴만)으로 하면 카메라 대신 스마트폰 앱 (iPhone의 Waidayo 등)에서 VMC 프로토콜로 얼굴 움직임을 받습니다. PC와 스마트폰을 같은 Wi-Fi에 연결하고, 트래킹 탭에 나오는 이 PC의 IP 주소와 UDP 포트(기본 39539)를 앱의 전송 대상에 입력하세요. 처음에는 Windows 방화벽 확인 창이 나오므로 개인 네트워크에서 허용하세요. ARKit 값을 보내는 앱이라면 퍼펙트 싱크와 표정 반영도 사용할 수 있습니다 (팔·손은 움직이지 않습니다).
  • 입력 소스를 iFacialMocap (iPhone, 얼굴만)으로 하면 iPhone의 iFacialMocap에서 얼굴 움직임을 받습니다. PC와 iPhone을 같은 Wi-Fi에 연결하고, iFacialMocap 화면 위쪽에 나오는 IP 주소를 트래킹 탭의 iPhone IP 주소에 입력하세요 (UDP 포트 49983을 사용합니다). 처음에는 Windows 방화벽 확인 창이 나오므로 개인 네트워크에서 허용하세요. 퍼펙트 싱크와 표정 반영도 사용할 수 있습니다 (팔·손은 움직이지 않습니다).
  • 정면이 어긋나면 카메라를 보고 패널 아래쪽 초기화의 얼굴 방향 (얼굴·상체·시선)을 누릅니다. 시선만이라면 시선.
  • 정면은 트래킹 시작 시 (입력 소스·카메라 변경 후에도) 머리가 0.5초 정도 멈췄을 때의 방향으로 자동으로 정해집니다. 손으로 얼굴을 가리는 등으로 놓쳐도 정면은 다시 잡지 않습니다.
  • 몸의 움직임에서 머리 움직임에 맞춰 상체를 기울일지 몸 전체를 움직일지 선택할 수 있습니다.

다른 앱 (Discord·Zoom·VSeeFace 등)이 웹캠을 사용 중이면 시작할 수 없습니다.

설정·초기화 (설정 탭)

  • 표시 언어: 자동 (OS에 맞춤) / English / 日本語 / 한국어 / 简体中文 / 繁體中文. 패널 위쪽의 언어 버튼으로 어느 탭에서든 바꿀 수 있습니다.
  • UI 크기: 75%~200%.
  • 테마: 라이트 (기본) / 다크. 표시 탭에서 배경색을 바꾸지 않았다면 배경도 테마에 맞춰 바뀝니다.
  • 저부하 모드 (기본은 켜짐): 화면을 30fps (끄면 60fps)로 제한하고 OpenSeeFace는 가벼운 모델을 써서 게임이나 OBS와 함께 쓸 때의 부하를 줄입니다. MediaPipe의 부하는 트래킹 탭의 트래커 동작에서 고릅니다.
  • 동작 상태 표시 (기본은 켜짐): 패널 맨 아래에 화면 FPS·VRCast의 CPU 사용률·GPU 처리 시간·내장 트래커의 CPU 사용률·트래킹 수신 속도를 영어로 표시합니다 (1초마다 갱신). 무거울 때 원인을 짐작하는 데 쓸 수 있습니다.

  • CPU 설정 › AMD (X3D) › 3D V-Cache가 없는 쪽 코어에서 실행 (기본은 켜짐. 7950X3D / 9950X3D 등 3D V-Cache가 한쪽 CCD에만 있는 CPU에서만 효과가 있으며, 이 PC가 대상인지는 설정 아래에 표시됩니다): 게임 중에는 Windows가 앱을 게임과 같은 코어로 모으므로, VRCast 본체와 내장 트래커를 반대쪽 코어에서 실행해 게임과 코어를 다투지 않게 합니다 (바로 적용). VRCast 자체가 게임으로 판정되면 Game Bar(Win + G) 설정에서 「이것을 게임으로 기억」을 꺼 주세요.
  • CPU 설정 › Intel (P 코어 / E 코어) › 사용할 코어 (기본은 「자동」. P 코어와 E 코어가 있는 Intel CPU(12세대 이후, Core Ultra)에서만 효과가 있습니다): VRCast 본체와 내장 트래커를 실행할 코어를 고릅니다 (바로 적용). E 코어만은 P 코어를 게임에 양보하지만 트래킹과 렌더링이 느려질 수 있습니다. P 코어만은 빠르지만 게임과 코어를 다툽니다. 잘 모르겠으면 「자동」으로 두세요.
  • 렌더링에 사용할 GPU (기본은 「자동」): 자동 / 절전 / 고성능을 고르거나 목록에서 GPU를 직접 고를 수 있습니다. VRCast를 다시 시작하면 적용됩니다 (VRCast 지금 다시 시작 버튼. PC 재시작은 필요 없습니다). OBS 캡처나 가상 카메라를 쓸 때는 OBS와 같은 GPU가 가장 가볍습니다. 내장 트래커는 CPU로 동작하므로 이 설정과 관계없습니다.
  • NVIDIA 인스턴트 리플레이 (NVIDIA GPU가 있는 PC에서만 표시): NVIDIA 인스턴트 리플레이가 감지하지 않게 하기를 누르면 VRCast가 인스턴트 리플레이(ShadowPlay)에 게임으로 감지되지 않도록 드라이버 설정에 VRCast용 프로필을 씁니다. VRCast를 다시 시작하면 적용됩니다. NVIDIA 인스턴트 리플레이 감지 되돌리기로 되돌릴 수 있습니다. 비공식 설정이라 드라이버에 따라 효과가 없을 수 있습니다. 변경하지 못했다고 표시되면 VRCast를 관리자 권한으로 실행해 보세요.

문제 해결

아바타가 어둡다

표시 탭의 맑음 프리셋을 누르거나 환경광을 올리세요. 방향을 0 근처로 하면 정면에서 빛이 비춥니다. lilToon 등은 밝기가 텍스처 색까지로 제한되므로, 태양광을 올려도 일정 이상은 밝아지지 않습니다. 그럴 때는 아바타 밝기를 올리세요 (0.1~10, 1 = 머티리얼 그대로).

OBS에서 배경이 투명해지지 않는다

VRCast의 배경을 투명하게 하고, OBS는 게임 캡처 (윈도우 캡처가 아님)에서 투명도 허용에 체크되어 있는지 확인하세요.

OBS에 아무것도 표시되지 않는다

게임 캡처의 창으로 [VRCast.exe]: VRCast를 다시 선택하세요. VRCast를 최소화하면 표시되지 않을 수 있습니다.

드래그 앤 드롭이 안 된다

VRCast를 관리자 권한으로 실행하면 Windows 제한으로 드롭할 수 없습니다. 일반적으로 실행하거나 파일 선택...을 사용하세요.

게임이나 OBS와 함께 쓰면 트래킹이 끊긴다

설정 탭의 저부하 모드가 켜져 있는지 확인하세요 (기본은 켜짐). MediaPipe라면 트래킹 탭의 트래커 동작을 부드럽게로 하면 부하가 줄고, 절약으로 하면 다시 절반 정도가 됩니다 (기본값인 매끄럽게 (고부하)는 손가락을 매끄럽게 움직이기 위해 무거운 편입니다). 그래도 무거우면 쓰지 않는 팔·손 트래킹을 끄면 부하가 줄어듭니다. 프로세스 우선순위를 「보통 이상」으로 하는 것도 효과가 있습니다.

립싱크가 안 된다

얼굴 탭에서 올바른 마이크가 선택되어 있는지, 음량 미터가 움직이는지 확인하고, 움직이지 않으면 마이크 감도를 올리거나 노이즈 게이트를 낮추세요.

표정이 바뀌지 않는다

표정 반영은 MediaPipe·iPhone·외부 앱 (VMC)·iFacialMocap만 지원합니다. 트래킹 탭에서 입력 소스가 그중 하나인지, 표정 반영이 켜져 있는지 확인하세요. 반응이 약하면 표정 임계값을 낮추고, 다른 표정이 나오면 표정별 선택에서 사용할 표정을 지정하세요.

카메라가 인식되지 않는다·트래킹이 안 된다

먼저 트래킹 탭의 카메라에서 사용 중인 웹캠이 선택되어 있는지 확인하세요. VRCast Camera(VRCast의 가상 카메라)·OBS Virtual Camera 등의 가상 카메라나 얼굴 인증용 적외선(IR) 카메라를 선택하면 영상은 들어와도 얼굴이 인식되지 않습니다.

디버그 로그 탭을 열면 카메라 목록·트래커 상태와 시작 후의 로그를 확인할 수 있습니다. WARN / ERROR만 표시하거나, 카테고리를 Tracker / TrackerOutput / Tracking(카메라 관련)으로 좁힐 수 있습니다. 문제를 보고할 때는 표시 중 복사를 눌러 로그와 환경을 그대로 붙여 넣어 주세요.

원인을 알 수 없을 때는 상세 로그를 켜고 증상이 나타날 때까지 기다린 뒤 복사해 주세요. 수신 통계(초당 데이터 수, 얼굴·팔·손이 보였던 비율)와 MediaPipe 추정 시간 등이 DEBUG로 기록됩니다. 설정은 저장되므로 조사가 끝나면 다시 꺼 주세요.
