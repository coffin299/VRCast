かんたんスタートQuick start

VRCast は VRChat 用のアバターを単体で表示し、OBS などの配信ソフトに映すアプリです。 VRCast を起動すると左のパネルに はじめに タブが開き、同じ手順を画面上で案内します。

VRCast shows a VRChat avatar on its own and sends it to streaming software such as OBS. When VRCast starts, the Start tab in the left panel guides you through the same steps.

  1. Unity でアバターを .vrcaster ファイルに書き出す Export your avatar to a .vrcaster file in Unity
  2. .vrcaster を VRCast のウィンドウにドラッグ＆ドロップ Drag and drop the .vrcaster file onto the VRCast window
  3. はじめに タブの 透過にする を押す Press Make transparent in the Start tab
  4. OBS で ゲームキャプチャ を追加して 透過を許可 Add a Game Capture source in OBS and check Allow Transparency
  5. Tab キーで操作パネルを隠す Press Tab to hide the control panel

1. アバターを書き出す（Unity）1. Export your avatar (Unity)

アバターの入った Unity プロジェクト（VCC で作ったプロジェクトで OK、Unity 2022.3.22f1）で作業します。

Work in the Unity project that contains your avatar (a VCC project is fine, Unity 2022.3.22f1).

  1. メニュー Window > Package Manager を開き、左上の + から Add package from git URL... を選んで次の URL を入力します。 Open Window > Package Manager, click + at the top left, choose Add package from git URL... and enter:
    https://github.com/coffin299/VRCast.git?path=/Packages/com.vrcast.converter
  2. メニュー VRCast > Avatar Exporter を開きます。 Open VRCast > Avatar Exporter.
  3. シーン上のアバター（一番上の親オブジェクト）を指定して Export... を押し、保存先を選びます。 Select your avatar root in the scene, press Export... and choose where to save.

元のアバターは変更されません。表情・口パク・まばたき・揺れもの・Constraint の設定も一緒に書き出されます。

Your original avatar is not modified. Expressions, lip sync, blink, PhysBones and constraints are exported too.

2. VRCast で読み込む2. Load it in VRCast

  • .vrcaster ファイルを VRCast のウィンドウにドラッグ＆ドロップすると読み込まれます。 Drag and drop a .vrcaster file onto the VRCast window.
  • または はじめに タブの ファイルを選ぶ...、 アバター タブの 参照... で選べます。 Or use Choose file... in the Start tab, or Browse... in the Avatar tab.
  • 最後に読み込んだアバターは次回起動時に自動で読み込まれます。 The last avatar is loaded automatically the next time you start VRCast.

.vrcaster 以外のファイル（画像や unitypackage など）は読み込めません。エラーが表示された場合は書き出し直してください。

Only .vrcaster files can be loaded (not images, unitypackages, etc.). If you see an error, export the avatar again.

3. OBS に映す3. Show it in OBS

  1. VRCast の はじめに タブ（または 表示 タブ）で背景を 透過 にします。 VRCast の画面では背景色のまま見えますが、OBS では背景が抜けます。 In VRCast, turn on transparency in the Start tab (or the Display tab). The VRCast window keeps showing the background color, but OBS removes it.
  2. OBS の ソース の + から ゲームキャプチャ を追加します。 In OBS, click + under Sources and add Game Capture.
  3. モードを 特定のウィンドウをキャプチャ、ウィンドウを [VRCast.exe]: VRCast にします。 Set Mode to Capture specific window and Window to [VRCast.exe]: VRCast.
  4. 透過を許可 にチェックを入れます。 Check Allow Transparency.
  5. VRCast で Tab キーを押して操作パネルを隠します（パネルも OBS に映るため）。 Press Tab in VRCast to hide the control panel (it also appears in OBS).

ウィンドウキャプチャ は透過に対応していません。透過したいときは必ず ゲームキャプチャ を使ってください。

Window Capture does not support transparency. Always use Game Capture for a transparent background.

仮想カメラ（Discord / Zoom など）Virtual camera (Discord / Zoom, etc.)

  1. 出力 タブで仮想カメラの出力を ON にします。 Turn on the virtual camera output in the Output tab.
  2. 初回だけ ドライバーを登録 を押します（管理者の確認が出ます）。 The first time only, press Install driver (an administrator prompt appears).
  3. 使いたいアプリのカメラ選択で VRCast Camera を選びます（出ない場合はそのアプリを再起動）。 Choose VRCast Camera as the camera in the other app (restart that app if it is not listed).

操作パネルは仮想カメラには映りません。Discord などは透過できないため、背景は背景色で映ります。 VRCast のフォルダを移動・削除する前に ドライバーを解除 を押してください。

The control panel is not sent to the virtual camera. Apps like Discord cannot show transparency, so the background color is shown. Press Uninstall driver before moving or deleting the VRCast folder.

見た目・ライト（表示タブ）Look & lighting (Display tab)

項目Item内容What it does
カメラCamera 画角の変更とリセット。右ドラッグで回転、中ドラッグで移動、ホイールでズーム。 Field of view and reset. Right-drag to rotate, middle-drag to pan, wheel to zoom.
背景Background 背景色（既定はベージュ）と透過の切り替え。透過中も VRCast の画面では背景色が見えますが、OBS のゲームキャプチャでは抜けます。 Background color (beige by default) and transparency. While transparent, the VRCast window still shows the color but OBS Game Capture removes it.
解像度Resolution ウィンドウの大きさ（横長・縦長のプリセット）。 Window size presets (landscape / portrait).
ライトLight 環境光 はアバター全体を均一に明るく、太陽光 は一方向から照らします。 暗いときは 晴れ プリセットを押すか環境光を上げてください。太陽光の色 は低いほど暖色。 向き 0 で正面から当たります。 Ambient lights the whole avatar evenly; Sunlight shines from one direction. If the avatar looks dark, press the Sunny preset or raise Ambient. Lower Sun color is warmer. Direction 0 lights the avatar from the front.

ポーズ・表情 タブではアバターの向き・腕の下ろし方・表情（数字キー 1〜9、0 でニュートラル）を変更できます。

In the Pose tab you can change the avatar's direction, arm pose and expressions (number keys 1-9, 0 for neutral).

口パク・まばたき（顔タブ）Lip sync & blink (Face tab)

  • マイクで口パク を ON にしてマイクを選び、音量 メーターを見ながら マイク感度 と ノイズゲート（この音量以下は無音）を調整します。 Turn on Lip sync (microphone), choose your mic, and adjust Mic gain and Mic gate (sound below this is ignored) while watching the Level meter.
  • 母音で口の形を変える が ON なら、VRChat と同じように「あいうえお」で口の形が変わります。 判定がずれるときは 声の高さ補正 を動かします（声が高い人は右）。 With Vowel mouth shapes on, the mouth changes shape with the vowels (A I U E O), like VRChat. If vowels are misdetected, move Voice pitch (right for higher voices).
  • 揺れもの（PhysBone の近似）と自動まばたきも ON/OFF できます。 PhysBone physics (approximation) and auto blink can be turned on or off.

Web カメラトラッキング（トラッキングタブ）Webcam tracking (Tracking tab)

  • トラッキングを有効にする を ON にすると、同梱のトラッカーが自動で起動し、頭の向き・まばたき・口・視線（MediaPipe では腕・手も）が動きます。 Turn on Enable tracking. The bundled tracker starts automatically and drives head, blink, mouth and gaze (and arms/hands with MediaPipe).
  • カメラは < > で選びます。動かないときは トラッカーを再起動。 Choose the camera with < >. If nothing moves, press Restart tracker.
  • 正面がずれたらカメラを見て 姿勢をリセット。 If the front direction is off, look at the camera and press Reset pose.
  • 体の動き で、頭の動きに合わせて上半身を傾けるか体ごと動かすかを選べます。 Body chooses whether the upper body leans or the whole body moves with your head.

他のアプリ（Discord・Zoom・VSeeFace など）が Web カメラを使っていると起動できません。

The tracker cannot start while another app (Discord, Zoom, VSeeFace, etc.) is using the webcam.

設定・リセット（設定タブ）Settings & reset (Settings tab)

  • 表示言語: 自動（OS に合わせる）/ English / 日本語。 Display language: Auto (OS) / English / 日本語.
  • UI の大きさ: 75%〜200%。 UI size: 75% to 200%.
  • 設定は VRCast の終了時に自動で保存され、次回起動時に復元されます。 Settings are saved when VRCast closes and restored next time.

全ての設定をリセット（赤いボタン）を押し、確認で リセットする を押すと、全ての設定が初期状態に戻ります （ウィンドウサイズと最後に開いたアバターは残ります）。元に戻せません。

Press Reset all settings (red button), then Yes, reset to restore every setting to its default (window size and the last avatar are kept). This cannot be undone.

困ったときTroubleshooting

アバターが暗いThe avatar looks dark

表示 タブの 晴れ プリセットを押すか、環境光 を上げてください。 向き を 0 付近にすると正面から光が当たります。 lilToon 等は明るさの上限（マテリアルの設定）があるため、太陽光を上げても一定以上は明るくなりません。

Press the Sunny preset in the Display tab or raise Ambient. Set Direction near 0 to light the avatar from the front. Shaders such as lilToon cap brightness (a material setting), so raising Sunlight stops helping past a point.

OBS で背景が抜けないThe background is not transparent in OBS

VRCast の背景を 透過 にし、OBS は ゲームキャプチャ（ウィンドウキャプチャではなく）で 透過を許可 にチェックが入っているか確認してください。

Make sure VRCast's background is set to transparent, and that OBS uses Game Capture (not Window Capture) with Allow Transparency checked.

OBS に何も映らないNothing appears in OBS

ゲームキャプチャのウィンドウに [VRCast.exe]: VRCast を選び直してください。VRCast を最小化すると映らないことがあります。

Select [VRCast.exe]: VRCast again as the Game Capture window. Minimizing VRCast may stop the capture.

ドラッグ＆ドロップできないDrag and drop does not work

VRCast を管理者として実行していると Windows の制限でドロップできません。通常どおり起動するか、ファイルを選ぶ... を使ってください。

Windows blocks drops into apps running as administrator. Start VRCast normally, or use Choose file....

口パクしないLip sync does not move

顔 タブで正しいマイクが選ばれているか、音量 メーターが動くか確認し、 動かなければ マイク感度 を上げるか ノイズゲート を下げてください。

In the Face tab, check the selected microphone and that the Level meter moves. If not, raise Mic gain or lower Mic gate.

設定ファイル・ログの場所Settings and log files

%USERPROFILE%\AppData\LocalLow\VRCast\VRCast\ （settings.json と Player.log）。不具合の報告時は Player.log を添えてください。 (settings.json and Player.log). Please attach Player.log when reporting a problem.
