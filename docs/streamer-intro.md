# VRCast 紹介台本（動画配信者向け）

配信で使っている側として話します。見出しは読まず、本文だけ読みます。`（）` は画面に出すものの目印です。目安は2分です。

## 入り

配信に3Dアバターを出したくて、VRCast を使っています。使ってみて、ここがいいと思ったところを4つ話します。

## 1. 配信中に開くのは VRCast だけ

VRChat のアバターを配信に出すとき、Unity や VRChat を開いたままにするのは、けっこう重いです。VRCast は、アバターを一つのファイルにしておけば、配信中は VRCast だけを起動します。そのあいだ、Unity も VRChat も閉じていて大丈夫です。

準備は、最初の一回です。
（画面: Unity の書き出し）

VRChat 用のアバターは、いつもの Unity プロジェクトで `.vrcaster` というファイルに書き出します。VRoid などで作った VRM は、書き出しなしで `.vrm` をそのまま読み込めます。あとは、VRCast のウィンドウにドラッグします。
（画面: ファイルをドロップ）

## 2. いつものアバターが、ほぼそのまま出る

書き出した姿は、VRChat で見ている姿に近いところまで持っていけます。表情、着けている小物、髪や服の揺れが、配信の画面まで残ります。書き出しで、元のアバターが書き換わることもありません。

## 3. OBS にも、通話にも載せられる

背景を透過にすると、OBS のゲームキャプチャで、配信画面の上にアバターだけを重ねられます。VRCast の画面自体はベージュのままなので、こっちからは見やすいです。
（画面: OBS に重ねた配信画面）

Discord や Zoom では、カメラの一覧から「VRCast Camera」を選びます。ウェブカメラの代わりに、アバターが映ります。

## 4. 喋っている感じが、カメラとマイクで出る

動きは Web カメラです。頭の向き、視線、まばたき、口。それに腕、手、指まで追います。
（画面: トラッキング）

声はマイクです。あいうえおの形で口が動きます。カメラを止めて話しているあいだも、呼吸や体の揺れが入るので、絵が完全には止まりません。

## 締め

料金は無料です。動くのは Windows 11 です。ダウンロードと使い方のリンクは、概要欄に置いてあります。自分のアバターを配信に一枚載せたい人は、一度試してみてください。
