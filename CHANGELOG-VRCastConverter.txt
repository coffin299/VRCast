VRCast Converter（書き出しツール / unitypackage）更新履歴 / Changelog
======================================================================

`Packages/com.vrcast.converter`（アバターの Unity プロジェクトに入れる書き出しツール）の変更点です。
本体アプリの履歴は `CHANGELOG.txt` を見てください。配布 zip の `VRCast\` と `VRCast-Converter\` の両方に同梱されます。

新しいものが上です。各節は、その変更が載ったときのアプリ版です（converter の `package.json` の版は、
このファイルに追記するときだけ上げます。アプリだけのリリースでは触りません）。
Newest first. Section headers are the app version that shipped the change (raise
`Packages/com.vrcast.converter/package.json` only when this file gets new entries).

■ 3.0.4 (2026-10-18)

[日本語]
- 書き出したアバターがアプリで砂嵐やマゼンタになることがある問題をさらに修正（ライトマップ／フォグ／インスタンス用のバリエーションが削られないようにし、ライティング向けのキーワードも集める。既に書き出したアバターは書き出し直しが必要）

[English]
- Further fixed exported avatars sometimes showing noise or pink in the app (keep lightmap/fog/instancing variants and collect lighting keywords; re-export existing avatars)

■ 3.0.2 (2026-10-18)

[日本語]
- 書き出したアバターがアプリで砂嵐やマゼンタになることがある問題を修正（書き出し時に、使っているシェーダーのバリエーションを集め同梱する。既に書き出したアバターは書き出し直しが必要）
- 書き出しプレビューが Unity プロジェクト側のシェーダーで表示されているとき、アプリと見た目が違うことがある旨を警告するように追加
- 配布 zip の本体フォルダにも更新履歴を同梱するように追加

[English]
- Fixed exported avatars sometimes showing noise or pink in the app (collect and include used shader variants at export; re-export existing avatars)
- Added a warning when the export preview may be using shaders from the Unity project so the app can look different
- Added including this changelog in the main folder of the distribution zip

■ 2.2.1 (2026-10-15)

[日本語]
- リップシンクを FX のアニメーションで動かす作りのアバター（Lip Sync が Viseme Parameter Only など）向けに、必要なデータを書き出すように変更（顔以外に歯や舌のメッシュを一緒に動かすアバターにも対応。既に書き出したアバターは書き出し直しが必要）
- エクスポーターのウィンドウに、書き出しの進み具合と結果を表示するように変更（今どの工程かが分かり、途中で中断できます。書き出し後は同じウィンドウで、書き出したファイルのアバターをプレビューでき、腕を動かして衣装が体についてくるかを確かめられます。書き出しの記録を日本語・英語で表示し、書き出したファイルの横に「〜.log.txt」として保存します。ほかのツールが出したエラーも記録に入ります）
- 書き出し時に、衣装の姿勢がアバターと合っていない（T ポーズの衣装を A ポーズのアバターに着せた等）・体に追従しないメッシュがあることを知らせる機能を追加
- エクスポーターに「アバターと合わない衣装の姿勢を直す」を追加（袖や脚が体から浮いてしまう衣装の腕・脚のボーンを、書き出すアバターの上でだけアバターの向きに合わせます。既定 OFF）

[English]
- Export now includes the data needed for lip sync driven by FX animations (such as Lip Sync set to Viseme Parameter Only), including avatars that also move teeth or tongue meshes (re-export previously exported avatars)
- The exporter window now shows the export progress and result (see which step is running and cancel it; after exporting, preview the exported avatar in the same window and move its arms to check that outfits follow the body; the export log is shown in Japanese or English and saved next to the exported file as "*.log.txt", including errors from other tools)
- Added warnings when exporting if an outfit's pose does not match the avatar (such as a T-pose outfit on an A-pose avatar) or if a mesh will not follow the body
- Added "Fix outfit poses that do not match the avatar" to the exporter (turns the arm and leg bones of outfits whose sleeves or legs float away from the body to match the avatar, in the exported avatar only; off by default)

■ 1.16.7 (2026-10-10)

[日本語]
- 最適化ツール（メッシュの統合など）を使ったアバターの FaceEmo の表情が、取り込めているのにアプリの表情一覧に出ない問題を修正
- FaceEmo の別々のモードが同じアニメーションを使っていると、片方しか表情一覧に出ない問題を修正
- FaceEmo のモードを値がすべて 0 などの理由で見送らず、BlendShape があればすべて取り込むように変更
- FaceEmo の表情を VRChat の Expression Menu（FaceEmo のサブメニュー）からも読むように変更（メニューと同じ名前で、改変を適用した後のアニメーションを使います）
- AAO（Avatar Optimizer）を使ったアバターの FaceEmo で編集した表情の BlendShape が最適化で消され、表情が動かない問題を修正（書き出すときだけ BlendShape の最適化を止めます）
- 最適化ツールがアニメーションを書き換えたアバターでは、FaceEmo の表情を書き換え後のアニメーションから読むように変更
- 表情の動かすメッシュが見つからないときに顔のメッシュ（リップシンク・まぶたに使うメッシュ）を使うように変更（BlendShape 名の大文字・小文字や区切り文字の違いも吸収します）
- 「追加の表情」で、小物の切り替えなども含むクリップや値がすべて 0 のクリップを見送らず、BlendShape の部分を取り込むように変更（FaceEmo のアニメーションを追加しても入らない問題を修正）
- 書き出した後に Console にレイアウトのエラーが出る問題を修正
- 結果に、動かすメッシュが見つからずアプリの表情一覧に出ない表情の数を表示する機能を追加

[English]
- Fixed FaceEmo expressions of avatars using optimization tools (such as mesh merging) being exported but not appearing in the app's expression list
- Fixed only one of several FaceEmo modes sharing the same animation appearing in the expression list
- Changed the exporter to take every FaceEmo mode that has blend shapes instead of skipping some (for example when all values are 0)
- Changed the exporter to also read FaceEmo expressions from the VRChat Expression Menu (the FaceEmo submenu), using the menu names and the animations after modifications are applied
- Fixed blend shapes of expressions edited in FaceEmo being removed by AAO (Avatar Optimizer) so the expressions did not move (blend shape optimization is turned off only while exporting)
- Changed the exporter to read FaceEmo expressions from the animations rewritten by optimization tools when they are present
- Changed the exporter to use the face mesh (the mesh used for lip sync and eyelids) when an expression's mesh is not found (differences in letter case and separators in blend shape names are also absorbed)
- Changed "Additional expressions" to take the blend shape part of clips that also toggle items or whose values are all 0 instead of skipping them (fixes FaceEmo animations not being added)
- Fixed a layout error appearing in the Console after exporting
- Added to the exporter result the number of expressions that will not appear in the app's expression list because their meshes were not found
