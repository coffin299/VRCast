# Contributing / コントリビューション

[English](#english) | [日本語](#日本語)

---

## 日本語

バグ修正・機能追加・ドキュメント改善などのプルリクエストを歓迎します。
人手の変更でも、AI を使った変更でも構いません。

### はじめに

- 大きな変更や方針に関わるものは、先に Issue や [Discord](https://discord.gg/vM5RH52HdF) で相談してもらえると助かります（必須ではありません）。
- 利用者に見える変更（バグ修正・機能追加など）には、同じ PR で `CHANGELOG.txt` の「未リリース / Unreleased」へ日本語・英語の追記をお願いします。書き出しツールだけの変更は `CHANGELOG-VRCastConverter.txt` へ。

### プルリクエスト

1. フォークしてブランチを切る
2. 変更を入れる（関連するテストがあれば通す）
3. 必要なら `CHANGELOG.txt`（または `CHANGELOG-VRCastConverter.txt`）を更新する
4. プルリクエストを送る（何を・なぜ変えたかを短く書いてください）

小さな修正でも大歓迎です。レビューで調整しながら進めましょう。

## English

Pull requests for bug fixes, new features, documentation improvements, and similar changes are very welcome.
Human-written and AI-assisted contributions are both fine.

### Getting started

- For large or design-heavy changes, opening an Issue or asking on [Discord](https://discord.gg/vM5RH52HdF) first helps—but it is not required.
- For user-visible changes (bug fixes, features, etc.), please also update the Unreleased section of `CHANGELOG.txt` in Japanese and English in the same PR. Converter-only changes go in `CHANGELOG-VRCastConverter.txt`.

### Pull requests

1. Fork and create a branch
2. Make your changes (run related tests if applicable)
3. Update `CHANGELOG.txt` (or `CHANGELOG-VRCastConverter.txt`) when needed
4. Open a pull request with a short note on what changed and why

Small fixes are welcome too. We can iterate together in review.
